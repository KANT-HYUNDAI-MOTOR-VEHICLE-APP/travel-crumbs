# 홈 「내 근처 리뷰 많은 로드맵」 가로 카드 목록(home-nearby) 스펙

## 1. 요약

- 정차 중 · 진행 중 여행이 없는 기록 칸(C-02) 맨 위 영역 아래에 「내 근처 리뷰 많은 로드맵」 구역 하나를 더함 — 가로로 밀어 넘기는 카드 목록(한 장씩 맞춰 멈춤 · 겹침 없음). 카드 = 경로 미리보기 · 이름 · 지역 · 별점 · 「리뷰 N명」 · 순위 · 내 위치에서 거리 · 누르면 「추천」 칸 B-04 상세.
- 고르는 법 = 내비 현재 위치(#51 A-02 와 같은 조회 · 새 권한 없음)에서 로드맵 첫 장소까지 거리 ≤ 반경(초안 10km)인 로드맵만 → 리뷰 수(별점 참여 인원 · 내 별점 포함) 많은 순 → 최대 10장. 위치를 못 얻으면 구역 없음 · 주행 · 모름이면 구역 없음.
- 내 위치 좌표는 기기 메모리에서 거리 계산에만 씀 — 화면 상태 · 로그 · 기기 저장 · 서버 어디에도 남기지 않음. 서버 · API · DB · Room 변경 없음(기기 안 추천 시드 + 내 공개 여행 + 별점 저장소).

## 2. 화면

### 2-1. 공통

- 주행 판정은 앱 틀 그대로(app-shell-v5 2절 판정 표) — 정차(PARKED)에서만 기록 칸 정차 화면이 그려짐 · 주행(DRIVING) · 모름(UNKNOWN)이면 주행 전용 화면이라 이 구역이 그려질 자리가 없음.
- 애니메이션은 밀어 넘김 손동작과 맞춰 멈춤(사용자 손에 따른 이동)만 · 자동 넘김 · 자동 회전 · 깜박임 · 돌아가는 진행 표시 없음.
- 화면 문구는 문자열 자원 한 곳 · 수치(반경 · 최대 장수 · 카드 폭)는 바뀔 값 한 곳(android-architecture 규칙 6).
- 아래 「」는 문구 초안 — 스펙 PR 리뷰에서 사람이 고칠 수 있음.

### 2-2. 기록 칸(정차 · 진행 중 여행 없음) 안 자리

## 3. 상태

### 3-1. 기록 칸 UiState 에 더하는 칸(이 구역)

| 칸 | 뜻 | 처음 값 |
|---|---|---|
| 구역 상태 | 없음 · 위치 확인 중 · 근처 있음 · 근처 없음(전국 대체) — 위치 못 얻음 · 대체 없음은 「없음」과 같게 그림 | 없음 |
| 카드 목록 | 카드 한 장 = 로드맵 번호(trip_no) · 순위 · 이름 · 시도 · 시군구 · 별점 평균 · 리뷰 수 · 거리(미터 · 정수) · 미리보기(도로 지도 평면 값 또는 경로 그림 상대 점 — 둘 다 실제 좌표 아님) | 빈 목록 |
| 반경(km) | E2 문구에 넣을 수치(설정값을 그대로) | 설정값 |
| 시연용 데이터 | E3 표시 여부 | 추천 저장소 값 |

- **좌표 칸 없음** — 내 위치 위도 · 경도 · 주소, 로드맵 장소 좌표 모두 UiState 에 넣지 않음. 거리(미터)와 실제 좌표가 아닌 미리보기 값만.
- 이 구역 칸은 프로세스 재생성 때 복원 대상이 아님(SavedStateHandle 에 넣지 않음) — 다시 그려질 때 3-2 대로 새로 계산. 밀어 둔 위치도 복원하지 않음(첫 카드부터).

### 3-2. 전이 · 위치 조회 시점

| 지금 | 일 | 다음 |
|---|---|---|
| 없음 | 정차 · 진행 중 여행 없음 · 기록 칸 정차 화면이 앞에 옴(화면 다시 보임 · 주행/모름 → 정차 · 진행 중 여행 끝남) | 위치 확인 중 + 조회 1회 |
| 위치 확인 중 | 위치 얻음 → 3-3 계산 → 반경 안 1장 이상 | 근처 있음 |
| 위치 확인 중 | 위치 얻음 → 반경 안 0장 · 반경 밖 1장 이상 | 근처 없음(전국 대체) |
| 위치 확인 중 | 위치 얻음 → 로드맵 0개(리뷰 0명 제외 뒤) | 없음 |
| 위치 확인 중 | 위치 못 얻음 — 내비 연결 안 됨 · 조회 오류 · 응답 한도(기존 SDK 응답 한도 10초) 지남 · 위치 동의 없음(N6 추천) | 없음(위치 못 얻음) |
| 위치 못 얻음 | 내비 연결이 「연결 안 됨 → 연결됨」으로 바뀜(화면이 앞에 있을 때) | 위치 확인 중 + 조회 1회 |
| 근처 있음 · 근처 없음 | 화면이 다시 앞에 옴 · 주행 → 정차 | 카드 그대로 두고 조회 1회 → 결과로 바꿈(결과가 위치 못 얻음이면 없음) |
| 근처 있음 · 근처 없음 | 내 별점 저장 · 내 공개 여행 변화(별점 저장소 · 추천 자료가 바뀜) | 마지막으로 얻은 거리로 다시 정렬 · 위치는 다시 묻지 않음(N7) |
| 아무 상태 | 주행 · 모름 · 진행 중 여행 시작 · 다른 화면이 기록 칸 차지 | 없음 · 진행 중 조회 결과는 버림 |
| 근처 있음 · 근처 없음 | 카드 누름 | 3-4 |

- 조회는 한 번에 하나 — 진행 중이면 새로 시작하지 않음. 주기적 갱신 · 백그라운드 조회 없음(화면이 안 보이면 조회하지 않음 · pleos-vehicle-sdk 5절 백그라운드 규칙).
- 「마지막으로 얻은 거리」는 화면이 살아 있는 동안 메모리에만 — 좌표 대신 로드맵별 거리만 남기는 것을 권장(좌표를 들고 있지 않아도 다시 정렬 가능).

### 3-3. 거리 계산 · 거르기 · 정렬

| 단계 | 규칙 |
|---|---|
| 대상 | 추천 칸과 같은 자료 — 모든 시도의 공개 로드맵(시연 시드 + 내 공개 여행) · 내 별점은 추천 칸과 같은 방식으로 평균 · 참여 수에 더함(#41) |
| 빼는 것 | 장소가 없는 로드맵 · 리뷰 수 0명(N3 추천) |
| 거리 | 내 위치 → 로드맵 **첫 장소**(장소 순서 place_ord 가 가장 작은 장소) 좌표 · 하버사인 직선 거리(미터) — 앱에 이미 있는 하버사인 계산과 같은 식(지구 반지름 6,371,000m) · 도로 거리 아님 |
| 거르기 | 거리 ≤ 반경(설정값 · 초안 10km · 경계값 포함) |
| 정렬 | ① 리뷰 수 많은 순 → ② 동률이면 거리 가까운 순 → ③ 그래도 같으면 별점 평균 높은 순 → ④ 로드맵 번호 작은 순(늘 같은 순서) |
| 자르기 | 위에서 최대 10장(설정값) |
| 순위 | 자른 목록에서 1부터 |
| 근처 0장(N2 추천 · 전국 대체) | 거르기 없이 같은 정렬 → 최대 10장 · 거리는 그대로 보임 |

### 3-5. 개인정보 규칙(위치)

- 내 위치(위도 · 경도 · 주소)는 기존 내비 현재 위치 조회로만 얻고, 거리 계산에 쓴 뒤 들고 있지 않음.
- 남기지 않는 곳: UiState · SavedStateHandle · DataStore · Room · 파일 · 로그(값 · 주소 · 거리 모두 — 로그엔 예외 종류 이름만) · 서버 요청 · 분석 이벤트 · LLM 입력.
- 화면에는 거리(km)만 · 좌표 숫자 · 내 위치 주소는 보이지 않음.
- 새 권한 없음 — 매니페스트 권한 목록이 이번 변경 전과 같음(센서 매니페스트 검사로 확인).

| N5 | 위치 소스 | ① 내비 현재 위치 조회 재사용 ② 프레임워크 위치 관리자 ③ Pleos FusedLocation | ① — ②는 위치 권한 · ③은 `FUSED_LOCATION` 권한이 새로 필요(이슈 「하지 않는 것」). **코드로 확인한 사실**: 내비 저장소에 현재 위치 1회 조회가 있음(#51 A-02 「이 장소 기록」이 씀) · NaviHelper `getCurrentLocationInfo` 를 부름 · 권한은 이미 선언된 `NAVI_ROUTE`(센서 허용 목록에 있음) · 내비 연결 안 됨 · 오류 · 10초 한도면 빈 값 · 로그엔 예외 이름만 · 다른 내비 조회와 같은 조회 창을 써 길안내 요청 결과와 섞이지 않음. **확인 못 한 것**: 길안내 중이 아닐 때도 늘 값을 주는지 · 값이 얼마나 자주 새로워지는지 · 에뮬레이터 위치(확장 컨트롤 · GPX)를 내비가 따르는지 · Pleos 문서상 이 조회가 `NAVI_ROUTE` 범위인지(코드 주석 근거뿐). #51 기록에 에뮬레이터 내비 현재 위치 주소가 「수정구 시흥동」(성남)으로 온 사례가 있음 — 한 번은 값을 줌 |
| N6 | 위치 동의 | ① LOCATION_COLLECT 동의 있을 때만 조회 ② 동의 무관(저장 · 전송 안 하므로) ③ 새 동의 유형(표준 등록) | ① — 안전 쪽. 단 그 동의의 정의가 「여행 기록용」이라 목적이 다름 · 법적 요건 확인(R14) 뒤 ② · ③ 으로 바꿀 수 있음. ①이면 첫 여행 전(동의 전) 사용자에겐 구역 없음 |
| N7 | 위치 갱신 시점 | ① 기록 칸이 앞에 올 때 · 정차 전환 · 내비 연결됨 전환에 1회 ② 주기 갱신(예: 1분) ③ 앱 실행 때 1회만 | ① — 정차 중 홈을 다시 볼 때 새 위치 · 백그라운드 · 주기 조회 없음(자원 · 개인정보). 별점 변화는 위치 없이 다시 정렬 |
| N8 | 카드 최대 장수 | ① 10 ② 5 ③ 제한 없음 | ① 10 — 밀어 넘기는 수가 과하지 않고 반경 안 수가 적은 지금 시드에서도 충분 |
| N9 | 에뮬레이터 시연 위치 | ① 에뮬레이터 확장 컨트롤 위치를 속초(중앙시장 공영주차장 38.2049, 128.5906)로 → 내비가 따르면 그대로 ② 내비가 안 따르면 debug 빌드 전용 시연 위치 고정(release 에 없음) ③ 반경을 키워 성남 위치에서도 보이게 | ① 먼저 확인 → 안 되면 보고 후 사람이 ② 결정. 참고: 이슈의 「시연 데이터가 강원뿐」은 사실과 다름 — 시드는 8개 시도 25개 · 강원 동해안만인 것은 **도로 지도 묶음**(속초 · 설악 · 경포 · 강릉 · 양양). 성남 시흥동 부근(#51 실측 주소)에서는 10km 안 시드가 거의 없음(강남 로드맵 첫 장소 약 10km 경계 · 추정치) |
| N10 | 진행 중 여행(정차)일 때 | ① 구역 없음 ② 기록 상태 아래에도 보임 | ① — 결정 ⑦ 의 자리(「여행 시작」 · 「추천 보러 가기」 아래)는 여행 없음 모양에만 있음 · 이슈 대상은 「목적지를 아직 못 정한 운전자」 |
| N11 | 구역 자리 | ① 맨 위 영역(최근 여행 포함) 아래 = 「가 볼 장소」가 있던 자리 ② 두 버튼 바로 아래 · 최근 여행 위 | ① — 결정 ⑦ 의 「가 볼 장소 자리」를 글자 그대로 따름 |
| N12 | 「시연용 데이터」 표시 | ① 구역 머리에 표시(추천 칸과 같은 규칙) ② 표시 안 함 | ① — 시드를 쓰는 화면은 모두 표시하는 기존 규칙(#37) · 심사 「등록 정보 · 콘텐츠」 오해 방지 |
| N13 | 홈에서 연 B-04 의 뒤로 | ① 기록 칸(온 곳) ② 그 지역 B-02 랭킹 | ① — 추천 칸 기존 규칙 「상세 뒤로는 온 화면으로」와 같음 |
| N14 | 「리뷰」 낱말 | ① 화면 문구만 「리뷰 N명」(데이터 이름은 rating) ② 「별점 N명」으로 | ① — 결정 ② 문구 그대로. 표준 「후기(review)」와 뜻이 달라 데이터 이름엔 쓰지 않음 · 사람 확인만 |
| N15 | 카드 폭 · 모양 | ① 폭 고정 360dp · 다음 카드 일부가 보임 ② 구역 폭의 일정 비율 ③ 사람이 정한 「첫 번째 샘플」 치수 | ③ 이 있으면 그 값 — 샘플 그림이 저장소에 없어 이 스펙은 ① 로 씀. 리뷰에서 샘플 치수를 주면 E5 만 고침 |
