# 홈 「내 근처 리뷰 많은 로드맵」 가로 카드 목록(home-nearby) 스펙

## 1. 요약 (수정: 리뷰 반영 — 별도 위치 동의 · 권한 확정 · 상태 계약)

- 정차 중 · 진행 중 여행이 없는 기록 칸(C-02) 맨 위 영역 아래에 「내 근처 리뷰 많은 로드맵」 구역 하나를 더함 — 가로로 밀어 넘기는 카드 목록(한 장씩 맞춰 멈춤 · 겹침 없음). 카드 = 경로 미리보기 · 이름 · 지역 · 별점 · 「리뷰 N명」 · 순위 · 내 위치에서 거리 · 누르면 「추천」 칸 B-04 상세.
- 위치 이용은 **이 기능 전용 별도 동의**(기존 LOCATION_COLLECT 와 독립 · 사람 결정) — 동의 전엔 구역 자리에 동의 카드 · 거부 · 철회면 구역 숨김 · 설정 C-03 에서 철회 · 다시 동의. 동의가 있을 때만 내비 현재 위치 조회(권한 NAVI_ROUTE · SDK 3.0.5 주석으로 확정 · 새 권한 없음) → 첫 장소까지 거리 ≤ 반경(초안 10km) → 리뷰 수 많은 순 → 최대 10장.
- 내 위치 좌표는 기기 메모리에서 거리 계산에만 쓰고 바로 버림 — 보유 · 제3자 제공 없음. 새로 남는 것은 기기 동의 이력 행(user_consent_hist · 기존 표 · 새 코드값 1개 — 표준 등록 필요 N17)뿐 · 서버 · API · DB 스키마 변경 없음.

## 2. 화면

### 2-1. 공통

- 주행 판정은 앱 틀 그대로(app-shell-v5 2절 판정 표) — 정차(PARKED)에서만 기록 칸 정차 화면이 그려짐 · 주행(DRIVING) · 모름(UNKNOWN)이면 주행 전용 화면이라 이 구역이 그려질 자리가 없음.
- 애니메이션은 밀어 넘김 손동작과 맞춰 멈춤(사용자 손에 따른 이동)만 · 자동 넘김 · 자동 회전 · 깜박임 · 돌아가는 진행 표시 없음.
- 화면 문구는 문자열 자원 한 곳 · 수치(반경 · 최대 장수 · 카드 폭)는 바뀔 값 한 곳(android-architecture 규칙 6).
- 아래 「」는 문구 초안 — 스펙 PR 리뷰에서 사람이 고칠 수 있음.

### 2-6. 상태별 구역 모양 (수정: 논리 상태 8개와 화면 표현을 1:1 로 · 동의 상태 추가)

| 대상 없음(NO_ROADMAP — 위치는 얻음 · 로드맵 0개) | 그리지 않음 | — |
| 위치 못 얻음(LOCATION_UNAVAILABLE — 내비 연결 안 됨 · 조회 오류 · 한도 지남) | 그리지 않음 | 안내 한 줄 없음(구역이 조용히 빠짐 · 미확정 N5). 논리 상태로는 대상 없음 · 동의 안 함과 구분됨(3-2 회복 전이가 다름) |

- 위치 확인 중 → 결과가 나오면 같은 자리에서 바뀜. 위치 못 얻음이면 그때 구역이 빠짐(정차 화면이라 자리 이동을 허용 · 주행 중 화면이 아님).
- 다시 조회하는 동안(3-2 T4 · T18) 이미 보이던 카드는 그대로 두고 결과가 오면 바꿈 — 위치 확인 중 모양으로 되돌아가지 않음(깜박임 없음).
- 동의 카드에서 동의하면 같은 자리가 위치 확인 중 모양으로 바뀜 · 거부하면 구역이 빠짐.

### 2-8. 근처 로드맵 위치 이용 동의 카드 (수정: 사람 결정 — 별도 동의 · 받는 자리 N18)

- 자리: 2-2 의 2번(구역 자리) — 구역 상태가 동의 필요일 때 카드 목록 대신 이 카드 한 장. 꼴은 A-06 추천 공개 동의 블록(카드 · 제목 한 줄 · 4줄 본문)과 같음 + 버튼 두 개. 높이는 내용만큼(카드 목록 고정 높이와 무관).
- 언제 보임: 정차 · 진행 중 여행 없음 · 기록 칸 정차 화면이 앞 · 근처 위치 동의 이력이 한 번도 없음. 거부 · 철회 뒤에는 다시 보이지 않음(N19 · N20).

| 번호 | 요소 | 문구 · 동작 |
|---|---|---|
| K1 | 제목 | 「근처 로드맵을 보려면 현재 위치를 써도 될까요」 · 한 줄 · 넘치면 두 줄 |
| K2 | 본문(4줄) | 「이용 항목 · 차량 내비가 알려 주는 지금 위치(위도 · 경도)\n목적 · 근처 로드맵을 고르고 여기서 얼마나 먼지 보여 줌\n보유 기간 · 저장하지 않아요 · 기기 안에서 거리만 계산하고 바로 버려요\n제3자 제공 · 없음 · 설정에서 언제든 철회할 수 있어요」 |
| K3 | 주 버튼 | 「동의하고 보기」 — 동의 이력에 동의 행 1개(유형 = N17 코드 · 여부 = Y) → 구역 상태 = 위치 확인 중 · 조회 1회(3-2 T6) |
| K4 | 보조 버튼 | 「괜찮아요」 — 동의 이력에 거부 행 1개(같은 유형 · 여부 = N) → 구역 상태 = 동의 안 함(숨김) · 조회 0회(3-2 T7 · N20) |
| K5 | 읽어 주기 | 제목 · 본문 한 묶음 · 버튼은 각각 |

- 동의 카드가 떠 있는 동안 위치 조회 0회 · 기존 LOCATION_COLLECT 동의 여부와 무관하게 이 카드가 뜸(확대 · 승계 아님).
- 누르기 전 주행 · 모름으로 바뀌면 카드는 누름 없이 사라지고 동의 이력은 그대로(행 0).

## 3. 상태

### 3-1. 기록 칸 UiState 에 더하는 칸(이 구역) (수정: 논리 상태 8개 · 전이 표와 같은 이름)

| 칸 | 뜻 | 처음 값 |
|---|---|---|
| 구역 상태 | 논리 상태 하나 — 자격 없음(INELIGIBLE) · 동의 필요(CONSENT_NEEDED) · 동의 안 함(CONSENT_DECLINED) · 위치 확인 중(LOCATING) · 근처 있음(NEARBY) · 전국 대체(NATIONWIDE) · 대상 없음(NO_ROADMAP) · 위치 못 얻음(LOCATION_UNAVAILABLE). 화면 표현은 2-6 표(숨김이 4개 — 자격 없음 · 동의 안 함 · 대상 없음 · 위치 못 얻음 — 이지만 논리 값은 서로 다름) | 자격 없음 |
| 카드 목록 | 카드 한 장 = 로드맵 번호(trip_no) · 순위 · 이름 · 시도 · 시군구 · 별점 평균 · 리뷰 수 · 거리(미터 · 정수) · 미리보기(도로 지도 평면 값 또는 경로 그림 상대 점 — 둘 다 실제 좌표 아님). 근처 있음 · 전국 대체에서만 비어 있지 않음 | 빈 목록 |
| 반경(km) | E2 문구에 넣을 수치(설정값을 그대로) | 설정값 |
| 시연용 데이터 | E3 표시 여부 | 추천 저장소 값 |

- **좌표 칸 없음** — 내 위치 위도 · 경도 · 주소, 로드맵 장소 좌표 모두 UiState 에 넣지 않음. 거리(미터)와 실제 좌표가 아닌 미리보기 값만.
- 동의 카드 문구는 문자열 자원 · UiState 칸은 구역 상태(동의 필요)뿐.
- 이 구역 칸은 프로세스 재생성 때 복원 대상이 아님(SavedStateHandle 에 넣지 않음) — 다시 그려질 때 3-2 대로 새로 계산. 밀어 둔 위치도 복원하지 않음(첫 카드부터). 동의 상태는 동의 이력(Room)에서 다시 읽으므로 재생성 뒤에도 같음.
- 설정 UiState 에 더하는 칸: 근처 위치 동의 날짜(동의함이면 연 · 월 · 일 · 아니면 없음) · 동의 팝업 열림 여부(기존 팝업 칸들처럼 재생성 뒤 유지).
