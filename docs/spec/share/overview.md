# 공유(share) — 로드맵 공개 · 둘러보기 · 별점 · 지역 랭킹

업무 4(성호 · 희주). 기획 초안(2026-11-06 · 최성호 결정 · AI 받아쓰기). 고르지 않은 곳은 「미정」.
이어지는 문서: 길안내 `docs/spec/navigation/` · 앱 뼈대 `docs/spec/app-shell/`.

## 1. 한 줄

여행이 끝나 핀들로 만들어진 **로드맵(+ 경험 태그 · 메모)을 공개**하고, 다른 사람은 **둘러보기**에서 로드맵을 열어 **장소를 골라 가거나** · **내 여행으로 가져오고** · **별점**을 줌. 별점과 안내 · 가져오기 횟수로 **시군구별 인기 로드맵 랭킹**을 보여 줌.

## 2. 흐름(시나리오)

1. 여행 중 목적지를 정하면 그 장소가 핀으로 남음(업무 2 · #4).
2. 여행이 끝나면 핀들이 로드맵(타임라인)이 됨(업무 3).
3. 로드맵을 **공개**함 — 올리기 전에 무엇이 공개되는지 미리 보여 주고 **동의**해야 올라감.
4. 다른 사람은 **둘러보기**에서 공개 로드맵을 보고
   - 로드맵 안 **특정 장소만 골라** 「가 볼 장소」에 담거나 · 바로 「여기로 안내」(정차 중만)
   - 로드맵을 통째로 **내 여행으로 가져옴**(복제)
   - 로드맵에 **별점**(1 ~ 5)을 줌
5. **지역 랭킹**: 먼저 **시 · 도** 목록(로드맵 수 · 1위)을 보여 주고, 시 · 도를 누르면 그 안 순위와 **시 · 군 · 구**로 더 들어감(전국 › 서울 › 종로구).

## 3. 결정(2026-11-06 · 최성호)

| 항목 | 결정 |
|---|---|
| 공유 경로 | **구조는 서버 · 시연은 같은 기기**(계정 전환) — 저장소 뒤에 기기 안 · 서버 두 구현(#4 와 같은 방식) |
| 공유 내용 | 로드맵 + 경험(태그 · 메모) |
| 공유 대상 | **공개(둘러보기)** · 지정한 사람에게 보내기 · 받은 여행함 · 배지(회의 P0)는 이번 범위에서 뺌 |
| 장소 표현(서버) | **이름 · 주소만** — 좌표는 서버에 두지 않음(하네스 규칙 유지) · 받는 쪽이 길안내 때 좌표를 다시 얻음 |
| 특정 장소 고르기 | 「가 볼 장소」에 담기 · 바로 「여기로 안내」 둘 다 |
| 공개 안전 장치 | 공개 전 미리보기 · 동의 · 공개 취소 · 삭제 |
| 별점 | 로드맵 전체에 1 ~ 5 |
| 지역 랭킹 | **인기 로드맵** · 기준 = 별점과 안내 · 가져오기 횟수를 섞음 · **시 · 도를 먼저 보여 주고 들어가면 시 · 군 · 구**(2단계 · 2026-11-06 목업 뒤 결정) · 지역은 주소에서 뽑음 |
| 시연 P0 | 공개 올리기 · 둘러보기 · 장소 담기 · 안내 · 내 여행으로 가져오기 · 별점 · 지역 랭킹 — 전부 |

## 4. 제약(기획 전 확인)

- **주행 규제**: 둘러보기 · 로드맵 · 공개 · 별점 · 랭킹 화면은 정차 중에만(#6 주행 판정 · D16). 주행 중 공유 알림 없음.
- **서버 경계**: 팀 서버 사용(#6 D19) · 서버에 좌표 없음 · Pleos 토큰 없음.
- **개인정보**: 로드맵 공개 = 이동 기록의 제3자 공개 — 동의 · 공개 범위 표시 · 취소 · 삭제.
- **콘텐츠 안전**: 메모(사용자 글)가 공개됨.
- **의존**: 여행 · 경유지 · 경험 태그 · 메모 · 로드맵 타임라인 = 업무 3(#3) · 계정 = 업무 1(#1) · 장소 담기 · 길안내 = 업무 2(#4).

## 5. 미정

| 항목 | 왜 · 누가 |
|---|---|
| 주소 → 좌표를 어디서 얻나 | NaviHelper `requestRoute` 는 위도 · 경도 필수 · Pleos Connect 에 Google Play 서비스 없음 → Android Geocoder · Pleos SDK 의 검색 기능 동작을 확인해야 함. 안 되면 장소 표현 결정을 다시 봄 |
| 랭킹 점수 공식 | 별점 평균과 안내 · 가져오기 횟수를 어떻게 섞나 · 별점 수가 적을 때 처리 |
| 로드맵의 지역 | 로드맵이 여러 시 · 도 · 시군구에 걸치면 어느 지역 랭킹에 넣나(목업은 걸친 곳마다 넣음) |
| 주소 형식 | 시 · 도 · 시군구를 뽑을 수 없는 주소의 처리 · 「서울시」 · 「서울」처럼 표기가 다른 시 · 도 묶기 · 「성남시 수정구」처럼 두 단계인 시군구 |
| 시 · 도 화면 | 시 · 도 목록의 정렬(로드맵 수 · 점수) · 1위 미리보기를 보일지 |
| 메모 공개 | 메모를 공개에서 빼는 선택 · 신고 기능 없음 — 심사 「콘텐츠 안전」 위험 |
| 「가져오기」로 복사되는 것 | 장소 순서 · 태그 · 메모 · 원작자 표시 · 가져온 뒤 원본이 바뀌면 |
| 별점 규칙 | 한 사람이 한 로드맵에 한 번 · 내 로드맵엔 못 줌 · 바꾸기 |
| 공개 취소 뒤 | 이미 가져간 복제본 · 받은 별점 · 랭킹에서 빠짐 |
| 둘러보기 위치 · 정렬 | 레일 항목(「둘러보기」) · 정렬(최신 · 인기) · 지역 필터(#6 레일 목록 한 곳에 더함) |
| 시연 계정 | 같은 기기 계정 전환에 쓸 시드 계정(#1 진행 상태에 따름) |
| 일정 | 시연 P0 가 전부라 범위가 큼 — 업무 3 모델 · 서버 · 계정이 늦으면 어디를 Mock 으로 둘지 |
