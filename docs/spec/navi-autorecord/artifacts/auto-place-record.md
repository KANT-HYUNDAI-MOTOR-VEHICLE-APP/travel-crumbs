# 내비 목적지 자동 장소 기록(navi-autorecord)

산출물 경로: `docs/spec/navi-autorecord/artifacts/auto-place-record.md`(새 파일)

## 1. 요약

- 기록 중(RECORDING)인 여행에서 운전자가 **차량 내비 앱에서 직접** 목적지를 정해 안내를 시작하면, 그 목적지(이름 · 주소 · 좌표 — 내비의 목적지 정보)를 현재 여행의 장소 1곳(`trip_place_dtl` · `draft_yn = Y`)으로 자동 기록. 「이 장소 기록」을 누른 것과 같은 모양.
- 위치 수집 동의(`LOCATION_COLLECT`)가 있을 때만 · 같은 목적지(현재 여행 장소와 100 m 안) · 재탐색은 한 번만 · 이 앱이 요청한 안내(추천 「안내 시작」 · 길안내 입구)는 기존대로 핀만 남기고 자동 기록하지 않음 · 앱이 멈춰 시작 알림을 놓쳤으면 화면 복귀 · 내비 재연결 때 한 번 조회해 맞춤(주기 조회 없음).
- 주행 · 모름 중엔 화면 알림 · 입력 없음(장소 수만 늘어남) · 정차 뒤 「이어서 쓰기」 → A-03 시트로 이름 · 태그 · 메모를 이어 입력. 서버 · API · DB · 표준 단어 · 권한 변경 없음.

## 2. 화면

새 화면 없음. 자동 기록은 화면과 무관하게 앱 안에서 일어나고, 결과는 기존 화면의 「장소 수」 · 「이어서 쓰기」 띠 · A-03 시트 · 장소 목록으로 보임. 화면이 앞에 없어도(내비가 앞 · 앱 얼림) 기록됨.

### 2.1 기록 칸(정차 홈 · 진행 중 여행) (#66)

| 요소 | 자동 기록 뒤 |
|---|---|
| 맨 위 영역 장소 수(「장소 %1$d곳」) | +1 — 「이 장소 기록」과 같음 |
| 한 줄 안내 | 정차(PARKED) · 기록 칸이 화면에 보이는 동안 자동 기록이 일어났을 때만 「목적지를 장소로 기록했어요 · 태그는 나중에」(새 문구 · N8) — 기존 한 줄 안내와 같은 자리 · 같은 시간만 보이고 사라짐 |
| A-03 시트 | **자동으로 열지 않음**(「이 장소 기록」 정차 때와 다름 · 운전자가 내비를 조작 중일 수 있음 · N7) |
| 「이어서 쓰기」 띠 | 2.3 규칙대로 남은 경우 기존 띠 「작성 중이던 내용이 있어요」 · 「이어서 쓰기」 그대로 |

### 2.2 주행 화면(A-02) (#66)

| 요소 | 자동 기록 뒤 |
|---|---|
| 장소 수 | +1(화면이 앞이면 바로 · 아니면 다음에 보일 때) |
| 한 줄 안내 · 팝업 · 소리 · 화면 전환 | 없음(완료 조건 「주행 중 화면 알림 · 입력 없음」 · 주의 분산 최소화) |

### 2.3 「이어서 쓰기」 띠 → A-03 장소 기록 · 태그 시트 (#66)

- 자동 기록 1건마다 「이어서 쓰기」 칸에 그 장소를 남김 — **칸이 비어 있을 때만**(이미 작성 중 내용 · 다른 장소가 있으면 덮어쓰지 않음 · N6). 주행 · 정차 · 모름 무관.
- 정차 뒤 띠의 「이어서 쓰기」 → 기존 A-03 시트가 그 장소로 열림:

| 요소 | 값 |
|---|---|
| 제목 | 「이 장소를 기록했어요」(기존) |
| 기록 시각 | 「기록 %1$02d:%2$02d」 = 자동 기록한 때(내비가 안내를 시작한 때가 아님 · 4.1) |
| 장소 이름 칸 | 내비 목적지 이름(고칠 수 있음) · 이름이 비었으면 주소에서 만든 처음 값 · 둘 다 없으면 빈 칸 |
| 태그 · 메모 · 「건너뛰기 · 나중에」 · 「저장」 | 기존 그대로(「저장」 → `draft_yn = N` · 「건너뛰기」 → `Y` 로 남음) |

### 2.4 장소 목록(A-05 로드맵 검토 · A-08 내 로드맵 상세) (#66)

- 자동 기록 장소는 「이 장소 기록」 장소와 **같은 모양**(출처 표시 없음) — 순서 = 기록 순 · 이름 · 「미완성」 표시(`draft_yn = Y` 동안) · 「+ 태그 달기」 → A-03.

| 위치 수집 동의 | 동의함 · 동의 안 함(이력 없음 · 거부 · 철회) · 못 읽음 | 기존 동의 이력 최신 행 |
| 내비 연결 | 연결됨 · 미연결 | 기존 내비 연결 상태 |
| 내비 안내 | 안내 중(목적지 있음) · 안내 중 아님 · 조회 실패 · 한도 지남(10초) | 조회 — 안내 중일 때만 목적지 조회(F7) |
| 이 앱 요청 | 대기 · 요청 중(X) · 시작됨(X) · 실패(X) · TIMEOUT 뒤 기억 중(X) | 기존 길안내 요청 입구 |
| 현재 여행의 장소 | 지우지 않은 장소들의 좌표(좌표 없는 행은 빼고) | 기기 `trip_place_dtl` |
| 현재 여행의 핀 | 핀 장소 id → 앱 장소 목록의 좌표 · 이름 | 기기 핀 |

### 3.3 기록 판정 — 「목적지 확인」 한 번의 결과

「목적지 확인」은 두 때에만 함: ① 시작 알림(`onRouteStarted`)을 받음 ② 앱 화면이 다시 앞으로 옴 · 내비가 새로 연결됨(복귀 대조 · 3.5). 위에서부터 처음 맞는 행 하나만 적용.

| 순서 | 조건 | 결과 | 목적지 조회 |
|---|---|---|---|
| 1 | 여행 기록 상태 ≠ RECORDING(PAUSED · 여행 없음 · 끝남 · 못 읽음) | 기록 안 함 | 안 함 |
| 2 | 위치 수집 동의 ≠ 동의함(못 읽음 포함) | 기록 안 함(위치 없는 장소도 만들지 않음 · F10 과 다름) | 안 함 |
| 3 | 내비 미연결 | 기록 안 함 | 안 함 |
| 4 | 내비 안내 = 안내 중 아님 · 조회 실패 · 한도 지남 | 기록 안 함(다음 확인 때 다시) | 안내 상태만 |
| 5 | 목적지 좌표가 쓸 수 없음(위도 −90 ~ 90 · 경도 −180 ~ 180 밖 · 둘 다 0) | 기록 안 함 | 함 |
| 6 | 이 앱 요청과 같은 목적지(3.6) | 기록 안 함(핀은 기존 규칙대로 · 이 기능은 핀을 만들지도 막지도 않음) | 함 |
| 7 | 현재 여행 장소와 중복(3.4) | 기록 안 함 | 함 |
| 8 | 그 밖 | **장소 1행 기록**(4.1) → 「이어서 쓰기」 칸(2.3) → 자동 기록 결과 | 함 |

- 확인은 한 번에 하나씩 차례로 — 시작 알림과 복귀 대조가 겹쳐 와도 둘째는 첫째가 저장한 행을 보고 7번에서 멈춤.
- 1 ~ 3 은 조회 전에 봄 — 동의가 없으면 목적지 좌표를 읽지도 않음.

### 3.4 중복 판단 (#66)

- 기준: **현재 여행(trip_no)의 지우지 않은 장소 가운데 좌표가 목적지 좌표와 100 m 안인 행이 하나라도 있으면 중복**(이름 · POI 번호는 보지 않음). 100 m = 기존 「목적지 같음」 반경과 같은 값 한 곳(N4).
- 비교 대상은 자동 기록 행만이 아니라 현재 여행의 모든 장소(「이 장소 기록」 행 포함 · 출처 칸이 없어 구분 못 함 · F12).
- 기기 저장 행과 비교하므로 앱 재시작 · 프로세스 종료 뒤에도 같음.
- 결과: 같은 목적지 다시 탐색 · 재탐색 · 경로 옵션 변경 · 취소 뒤 같은 곳 다시 시작 → 한 번만. 다른 목적지 B → 새 행. 다시 A(이미 기록됨) → 기록 안 함(같은 여행에서 같은 곳 재방문은 하나로 남음 · N4).

### 3.5 놓친 시작 되찾기(복귀 대조) (#66)

- 때: (a) 앱 화면이 다시 앞으로 옴(화면 재개 — 주행 화면 · 기록 칸 어느 쪽이든 1회) (b) 내비 연결이 새로 됨(앱 새로 시작 · 다시 연결). 각 1회 · 3.3 표 그대로.
- 주기 조회 없음 — 화면이 앞에 있는 동안 반복해서 묻지 않음(주행 화면 카드의 15초 다시 읽기를 쓰지 않음 · F14 · N2).
- 얼림이 풀린 직후엔 쌓인 알림이 먼저 지나가게 기존 1.5초 기다림 뒤 조회(F9).
- 기록 시각 = 대조한 때(실제 안내 시작 때를 모름 · 4.1).

### 3.6 이 앱 요청 안내와 구분 (#66)

목적지가 아래 하나에 맞으면 「이 앱 요청」으로 보고 자동 기록하지 않음(맞음 = 기존 판정 「이름 같음 + 좌표 100 m 안」).

| 대상 | 이유 |
|---|---|
| 요청 입구 상태가 요청 중(X) · 시작됨(X) · TIMEOUT 뒤 기억 중(X) 일 때의 X | 앱 요청의 시작 알림도 같은 리스너로 옴(F3) — 요청 입구가 핀을 남김 |
| 현재 여행의 핀 장소(앱 장소 목록의 이름 · 좌표) | 프로세스가 끝나 요청 입구 기억이 사라진 뒤의 복귀 대조에서도 이중 기록을 막음 |

- 요청 입구가 실패(X · TIMEOUT 아님)이거나 기억 기한(5분)이 지난 뒤 사용자가 내비에서 직접 X 를 시작하면: 핀 없음 · 위 둘째 행(핀)에도 없음 → 자동 기록함(사용자가 직접 시작한 것으로 봄).
