# 앱 뼈대(app-shell) — 화면 구조 · 주행 / 정차 모드

업무 2-A(희주 · 성호). 서버 없음 · 시연용. 공유 · 길안내는 각각 `docs/spec/share/` · `docs/spec/route/`.

## 1. 화면 방향

- landscape 고정 — 창 2개 영역 사용. Pleos 내비와 나란히 띄워 길안내 중에도 「기록 중」 표시 가능.
- 사용자가 창 위치 · 크기를 바꿔도 핵심 기능(기록 상태 · 장소 기록)은 유지.

## 3. 주행 / 정차 모드

### 주행 판정

- 기어 P = 정차 · R · N · D = 주행(R 후진도 주행).
- 주행 여부를 알 수 없으면(신호 못 읽음) 주행처럼 처리.

### 주행 중 — 주행 전용 화면 1장

- 보이는 것: 기록 상태(기록 중 · 일시정지) · 경과 시간.
- 버튼(크게 · 한 번 터치):
  - 「이 장소 기록」 — 현재 위치를 방문 장소로 표시. 경험 입력은 정차 뒤로 미룸.
  - 「음성 입력」 — 글레오 음성 트리거(#5).
  - 「기록 일시정지」 — 다시 누르면 재개.
- 키보드 입력 · 긴 글 · 목록 스크롤 · 애니메이션 · 자동 화면 전환 없음.
- 「이 장소 기록」(#3) · 「음성 입력」(#5)은 연결 지점만 둠 — 기능이 붙기 전엔 누르면 「준비 중」 짧은 안내.

### 정차 중에서 주행이 시작될 때

- 어느 화면에 있든 주행 화면으로 즉시 전환.
- 입력 중이던 내용은 임시 저장 → 정차하면 「이어서 쓰기」 제안.

### 정차 중

- 좌측 NavigationRail 로 화면 이동. 지금 항목: 홈 · 여행 · 설정. 받은 여행함 · 둘러보기 등은 share 기획 뒤 추가(추가하기 쉬운 구조).

## 4. 미정

| 항목 | 이유 · 누가 |
|---|---|
| 레일 메뉴 추가 항목 | share 별점 · 랭킹 결정 뒤 |
| 「기록 일시정지」 상태의 주인 | 실제 위치 수집 정지는 route(성호) — 상태 공유 방식 맞춤 |
| 임시 저장 범위 | 앱 종료 · 프로세스 재생성 뒤에도 「이어서 쓰기」가 남아야 하나(Pleos 가이드는 복원 요구) |
| 로그인 · 계정 전환 화면 위치 | #1(기보) |
| 딥링크 경로 이름(2-5) | #5(오륜 · 지수 · 기보)와 맞춤 |
| 주행 화면 버튼 수 | 3개로 정함 — 설계 가이드의 「최소 조작」과 대조 필요 |
| 백스택 정책(2-4) 세부 | 주행 화면 전환 규칙 외 정차 중 깊이 제한 |
| 화면 전환 애니메이션 · 세로 대응(2-6, P1) | 일정 여유에 따라 |
