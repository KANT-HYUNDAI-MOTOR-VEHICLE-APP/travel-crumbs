# 앱 뼈대(app-shell) — 화면 구조 · 주행 / 정차 모드 스펙

## 1. 요약

- 앱 틀 하나가 주행 판정(기어 + CarUxRestrictions · 모름은 주행처럼)을 보고 「정차 화면(좌측 NavigationRail · 홈 · 여행 · 설정)」과 「주행 전용 화면 1장」 중 하나만 그림. landscape 고정 · 창 크기가 바뀌어도 기록 상태 · 「이 장소 기록」 유지.
- 주행 화면 = 기록 상태 · 경과 시간 · 큰 버튼 3개(「이 장소 기록」 · 「음성 입력」 · 「기록 일시정지」). 앞의 둘은 #3 · #5 가 끼울 연결 지점만 두고 지금은 「준비 중」 짧은 안내. 일시정지는 표시 토글.
- 주행으로 바뀌는 순간 입력 중 내용을 기기 안에 임시 저장 → 정차로 돌아오면 「이어서 쓰기」 제안. 서버 · API 변경 없음. 선행 조건: 하네스 피드백 #2(DO 선언 허용) 반영 전엔 매니페스트 센서가 빨강.

## 2. 화면 (수정: 미확정 답 반영 — D4 · D6 ~ D11 · D13 결정 반영) (수정: #4 와 겹치는 지점 결정 — D16 주행 화면 안내 버튼 없음 · D17 홈 위아래 순서)

공통

- 방향: landscape 고정(Pleos 앱 구조 가이드 — landscape 지정 시 창 2개 영역 사용 · 결정 P3). 화면 전환 애니메이션 없음(범위 밖 · 넣지 않음).
- 창 크기: 전체 landscape · 에뮬레이터 landscape 창 1개 영역(분할 · 축소) 둘 다에서 아래 「핵심 요소」가 스크롤 없이 보이고 눌림. 기준 = 창 1개 영역(결정 D8) · 실측 크기는 builder 보고서에 · dp 수치화는 다음 이슈.
- 문구는 전부 문자열 자원(한 곳). 아래 「」 는 화면 문구 초안(결정 D14 — 스펙 PR 리뷰에서 사람이 고칠 수 있음).
- 주행 판정 → 무엇을 그리나

| 주행 판정 | 그리는 것 | 레일 |
|---|---|---|
| 정차(PARKED) | 정차 화면(선택된 레일 목적지) | 보임 |
| 주행(DRIVING) | 주행 전용 화면 | 없음 |
| 모름(UNKNOWN) | 주행 전용 화면(주행과 똑같이) | 없음 |

### 2-1. 앱 틀(정차 화면의 바깥 틀)

| 요소 | 내용 |
|---|---|
| 좌측 NavigationRail | 항목 3개 — 「홈」 · 「여행」 · 「설정」(아이콘 + 글자). 선택된 항목 강조. 처음 실행 시 「홈」 |
| 내용 영역 | 레일 오른쪽 · 선택된 목적지 화면 |
| 「이어서 쓰기」 띠 | 임시 저장된 내용이 있을 때만 내용 영역 위쪽에 표시 — 「작성 중이던 내용이 있어요」 + 버튼 「이어서 쓰기」 |

- 목적지 정의는 한 곳(목적지 목록)에 모임 — 항목 하나 = 목적지 id(고정 문자열) · 레일 글자 · 아이콘 · 화면 · 주행 중 허용 여부(지금 셋 다 「허용 안 함」). 받은 여행함 · 둘러보기 등은 이 목록에 한 줄 + 화면 파일 하나로 더해짐(이번엔 더하지 않음 · D15).
- 목적지 id: `home` · `trips` · `settings`(결정 D4 — 뒤에 딥링크(#5)가 가리킬 이름 · #5 에서 확정 · 목록 한 곳만 고치면 바뀜).
- 레일 항목 이동: 같은 단계 바꿔치기(쌓지 않음). 시스템 뒤로 — 홈 아닌 곳 → 홈 · 홈 → 앱을 뒤로 보냄.
- 「이어서 쓰기」 누름 → 저장 당시 목적지로 이동 + 저장 내용 복원 → 띠 사라짐 · 임시 저장 비움. 띠를 지우는 길은 이것 하나(결정 D13 · 「버리기」는 #3 때).

| 상태 | 표시 |
|---|---|
| 정차 | 위 표대로 |
| 주행 · 모름 | 앱 틀 전체가 주행 전용 화면으로 바뀜(레일 · 띠 · 목적지 화면 모두 안 그림) |

### 2-2. 홈(정차)

위에서 아래 순서(결정 D17)

| 순서 | 요소 | 내용 |
|---|---|---|
| 1 · 맨 위 영역 | 기록 상태 칸 | 「기록 중」 또는 「일시정지」 + 경과 시간(2-5 형식) |
| 1 · 맨 위 영역 | 버튼 「이 장소 기록」 | 주행 화면의 같은 버튼과 같은 연결 지점 · 지금은 「준비 중」 안내 |
| 2 · 기능 구역 자리 | 다른 기능이 붙이는 구역들 | 맨 위 영역 아래에 차례로 붙음(예: #4 「가 볼 장소」 · 그 안의 「여기로 안내」). 이 이슈는 자리와 순서 규칙만 정함 · 구역 내용은 만들지 않음 → 지금은 비어 있음 |
| 3 · 맨 아래 | SDK 확인 카드(기어 · 내비 · Gleo) | **debug 빌드에서만** 표시 · release 빌드엔 없음(결정 D9) |

- 순서 규칙: 맨 위 영역(기록 상태 · 「이 장소 기록」)은 늘 첫 자리 · 다른 기능 구역은 그 아래에만 들어옴 · 구역이 늘어도 맨 위 영역을 밀어내거나 가리지 않음(D17).
- 창 1개 영역으로 줄어도 맨 위 영역은 스크롤 없이 보임. 기능 구역 · debug 카드는 그 아래 · 스크롤 허용(정차 전용 화면).
- 「기록 일시정지」 · 「음성 입력」은 홈에 두지 않음(결정 D10).
- 길안내(「여기로 안내」)는 정차 홈의 기능 구역에서만 — 그 구역 자체는 #4 범위(D16).

### 2-5. 주행 전용 화면

| 요소 | 내용 |
|---|---|
| 기록 상태 | 「기록 중」 / 「일시정지」 — 큰 글자 · 고대비 |
| 경과 시간 | 「경과 {분}분」(1시간 미만) · 「경과 {시}시간 {분}분」(1시간 이상). 분 단위로만 바뀜(초 단위 깜빡임 없음 · 결정 D6) |
| 버튼 1 | 「이 장소 기록」 — 누름 → 「준비 중」 짧은 안내 |
| 버튼 2 | 「음성 입력」 — 누름 → 「준비 중」 짧은 안내 |
| 버튼 3 | 기록 중일 때 「기록 일시정지」 · 일시정지일 때 「기록 재개」 — 누를 때마다 토글 · 상태 글자도 함께 바뀜 |
| 「준비 중」 안내 | 화면 아래쪽 한 줄 · 짧게 보였다 사라짐(길이는 바뀔 수치 한 곳) · 화면을 가리거나 이동시키지 않음 |

- 버튼 3개 유지(결정 D6 — 각 버튼 한 번 터치로 끝 · 설계 가이드에 개수 수치 없음 · 시연 전 사람 확인).
- 길안내 버튼(「여기로 안내」 등) 없음 · 목적지 목록 · 선택 없음(결정 D16 — 주행 중 목록 선택은 운전자 주의 분산 · 목적지는 정차 중 홈에서 · 주행 중 목적지 변경은 「음성 입력」(#5) 몫).
- 버튼: 크게 · 한 번 터치로 끝 · 확인 대화상자 없음 · 길게 누르기 없음.
- 없는 것: 키보드 입력 칸 · 두 줄 넘는 글 · 스크롤(목록 · 화면 전체) · 애니메이션 · 움직이는 이미지 · 화면 안 자동 전환(회전 카드 등) · 레일 · 정차 전용 화면으로 가는 버튼 · 길안내 버튼.
- 창 크기: 전체 · 창 1개 영역 모두 요소 5개(상태 · 경과 · 버튼 3)가 스크롤 없이 보임. 좁으면 버튼을 세로로 쌓음.
- 시스템 뒤로: 정차 화면을 드러내지 않고 앱을 뒤로 보냄(결정 D7).
- Gleo 「OPEN_TRAVEL_CRUMBS」로 열려도 주행 판정대로 그림(주행 · 모름이면 이 화면). Gleo callback 동작은 그대로.

| 상태 | 표시 |
|---|---|
| 주행 | 위 표대로 |
| 모름 | 주행과 같음(별도 안내 글 없음) |
| 정차 | 그리지 않음 — 앱 틀(2-1)로 |

### 2-6. 모드 전환 규칙

- 정차 → 주행 · 모름: 어느 목적지에 있든 즉시 주행 전용 화면. 그 순간 입력 중 내용이 있으면 임시 저장(4절).
- 주행 · 모름 → 정차: 주행 직전에 보던 목적지로 즉시 돌아감(처음 실행부터 주행이었으면 「홈」). 임시 저장이 있으면 「이어서 쓰기」 띠.
- 전환은 애니메이션 없이 바로. 두 방향 모두 늦추지 않음 — 주차 중 P ↔ R 이 잦아도 그대로 따라감(결정 D11 · 시연 뒤 「정차 복귀만 짧게 늦춤」 검토).

## 3. 상태 (수정: 미확정 답 반영 — D1 · D2 · D3 · D12 결정 반영)

### 3-1. 주행 판정(도메인)

| 기어 | 주행 규제(CarUxRestrictions) | 판정 |
|---|---|---|
| R · N · D | 무엇이든 | DRIVING |
| 무엇이든 | 제한 있음 | DRIVING |
| P | 제한 없음 | PARKED |
| P | 모름 | PARKED(규제 신호를 못 받는 환경 — 기어만으로 판정 · builder 보고서에 에뮬레이터 수신 여부 적음) |
| 모름 | 제한 없음 · 모름 | UNKNOWN |

- 시작 직후 첫 값이 오기 전 = UNKNOWN → 정차여도 주행 화면이 잠깐 보임 · 대기 화면 없음(결정 D12 · 안전 쪽).
- 기존 「기어 → 판정」 순수 계산은 그대로 두고, 두 신호 합성 규칙을 위 표로 더함.

### 3-2. 앱 틀 UiState

| 칸 | 값 | 뜻 |
|---|---|---|
| drivingState | PARKED · DRIVING · UNKNOWN | 판정 그대로 |
| showDrivingScreen | Boolean | drivingState ≠ PARKED |
| selectedDestination | 목적지 id(`home` · `trips` · `settings`) | 정차 화면에서 고른 목적지(주행 중에도 기억) |
| draftAvailable | Boolean | 임시 저장 있음 → 「이어서 쓰기」 띠 |

### 3-3. 주행 화면 · 홈 기록 상태 UiState(공통 칸)

| 칸 | 값 | 뜻 |
|---|---|---|
| recording | RECORDING · PAUSED | 기록 상태 |
| elapsedMinutes | 0 이상 정수 | 기록 중 누적 경과(분) |
| message | 없음 · NOT_READY | 「준비 중」 안내 표시 · 화면이 보여 준 뒤 지움 |

- 기록 상태 · 경과는 이 이슈가 만드는 단일 출처 하나를 화면 둘(홈 · 주행)이 봄 — 한쪽에서 바꾸면 다른 쪽도 같음. route(위치 수집)는 뒤에 이 출처를 구독(결정 D1).

### 3-4. 전이

| 지금 | 사건 | 다음 |
|---|---|---|
| PARKED · 목적지 X | 판정 DRIVING · UNKNOWN | 주행 화면 · selectedDestination = X 유지 · 입력 중 내용 있으면 임시 저장 → draftAvailable = true |
| 주행 화면 | 판정 PARKED | 목적지 X 화면 · draftAvailable 그대로 |
| PARKED · draftAvailable | 「이어서 쓰기」 | 저장 당시 목적지로 이동 · 내용 복원 · draftAvailable = false |
| RECORDING | 「기록 일시정지」 | PAUSED · 경과 멈춤 · 버튼 글자 「기록 재개」 |
| PAUSED | 「기록 재개」 | RECORDING · 경과 이어서 증가 · 버튼 글자 「기록 일시정지」 |
| message 없음 | 「이 장소 기록」 · 「음성 입력」(연결 지점이 NOT_READY 돌려줌) | message = NOT_READY → 안내 표시 → 지움 |
| 설치 뒤 첫 실행(저장된 기록 상태 없음) | — | RECORDING · elapsedMinutes = 0 · 목적지 「홈」(결정 D2 · 임시 — route 기획 뒤 route 의 「여행 시작」에 맞춤) |

- 프로세스 재생성 뒤: selectedDestination · 기록 상태 · 경과 · 임시 저장 복원(Pleos 앱 구조 가이드 「프로세스 재생성 시 복원」).
- 앱 완전 종료 · 재부팅 뒤: 기록 상태 · 경과 · 임시 저장을 기기 안 저장에서 복원(결정 D3). 앱이 꺼져 있던 동안의 경과 계산은 미확정 N1.

## 4. 데이터 (수정: 미확정 답 반영 — D1 · D3 · D5 결정 반영)

### 4-1. 앱 모델(기기 안)

| 모델 | 칸 | 비고 |
|---|---|---|
| DrivingState(기존) | PARKED · DRIVING · UNKNOWN | 변경 없음 |
| 주행 규제 신호(새) | RESTRICTED · UNRESTRICTED · UNKNOWN | CarUxRestrictions 를 도메인 값으로 바꾼 것 · AAOS 타입은 data 밖으로 안 나감 |
| RecordingState(새) | RECORDING · PAUSED | 기록 상태의 단일 출처 · 이 이슈가 주인 · route(위치 수집)가 뒤에 구독(결정 D1) |
| 경과 | 누적 기록 시간(분 단위 표시용) | 일시정지 동안 멈춤 |
| Draft(새) | 목적지 id · 입력 칸 이름 → 내용(문자열 쌍) · 저장 시각 | 한 번에 하나 · 「이어서 쓰기」 하면 비움 |
| 버튼 연결 지점 결과(새) | DONE · NOT_READY · FAILED | 「이 장소 기록」(#3) · 「음성 입력」(#5) 각각 하나의 연결 지점 · 이번 기본 구현은 늘 NOT_READY |
| 목적지 목록(새) | id · 레일 글자 · 아이콘 · 주행 중 허용 | 레일 항목의 유일한 정의 · id `home` · `trips` · `settings` |

- 저장 범위: RecordingState · 경과 · Draft 는 기기 안에 남아 앱 종료 · 재부팅 뒤에도 복원(결정 D3). selectedDestination 은 프로세스 재생성까지만.
- 임시 저장 연결 지점: 입력 칸이 있는 화면(#3 의 경험 입력 등)이 「지금 입력 중 내용」을 등록 · 복원받는 자리. 이번 이슈엔 입력 칸 있는 화면이 없음 → 시험 전용 가짜 입력 화면(테스트 소스에만 · 앱 화면 아님)으로 UI · 단위 테스트(결정 D5).
- 바뀔 수치(「준비 중」 안내 길이 · 경과 표시 단위 등)는 한 곳.
