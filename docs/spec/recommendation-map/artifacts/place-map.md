# 추천 첫 화면 지도·공개 장소 핀 탐색 스펙

수정 이력: 2026-11-10 초안 · 2026-11-10 사용자 전국 지도 방향 확정 반영 · 2026-11-10 사람 결정 N1~N7 반영(앱에 묶은 전국 지도 · 기기 밖 지도 요청 없음 · 시도 탭 지도 이동 · 묶음 핀 · 첫 화면 10km 맞춤 · #55 동의 재사용) · 2026-11-10 PR #60 리뷰(성호님) 반영(N9 결정 — 출시 전이라 #55 문구에 추천 지도 목적 먼저 반영 · 재동의 없음 · 좌표를 ViewModel 상태에 두지 않는 #55 와 같은 규칙)

## 1. 요약 (수정: PR #60 리뷰 — N9 결정 · 좌표 상태 규칙)

- 추천 지역 선택(B-01) 아래 빈 영역에 앱에 묶은 한국 전국 지도(MapLibre 렌더러 + OpenStreetMap 벡터 지도 자산 · #54 추천 상세와 같은 어두운 도로 지도 스타일)를 그리고, 지도에 보이는 범위의 공개 장소 핀 선택 → 장소 카드 → 기존 안내 또는 로드맵 상세(B-04)로 연결하는 기능. 지도 그리기에 네트워크 · API 키 · 비용 없음 · 지도 요청이 기기 밖으로 나가지 않음.
- 처음 열면 내 위치 반경 10km 가 들어오게 맞춤(#55 「근처 로드맵 위치 이용」 동의 재사용 · 동의 없으면 위치 조회 없이 고른 시도 기준) · 정차 중 밀기 · 확대 · 축소 · 시도 탭 = 지도가 그 지역으로 이동 · 시군구 탭 = 지금처럼 랭킹(B-02) · 가까운 핀은 숫자 묶음 핀 · 한 화면 최대 50개.
- 핀 · 닉네임 · 별점 데이터는 기존 시연용 추천 시드 및 기기 안 공개 완료 여행뿐 · 서버 조회 · 전송 · DB 변경 없음. 구현 첫 단계에서 전국 지도 자산 크기와 MapLibre 의 Pleos 에뮬레이터 동작을 먼저 측정 · 확인(실패 시 사람 재결정) · 위치 사용은 #55 동의 카드 · 설정 행 문구에 「추천 지도」 목적 반영(성호님 #64 후속 · 출시 전이라 재동의 없음) 뒤 · 좌표(내 위치 · 공개 장소)는 지도를 그리는 쪽에만 두고 ViewModel 상태 · SavedStateHandle · 로그에 없음(#55 와 같은 규칙).

### 2-3. 핀 선택 장소 카드 · 묶음 핀 후보 목록 (수정: PR #60 리뷰 — 지도 위치 복원 주체)

- 지도와 같은 화면 안의 카드 하나 표시 · 지도 가림과 창 폭 변경에도 제목·두 주요 행동 접근 가능.
- 장소명·공개 로드맵의 작성자 닉네임·선택 장소의 태그·연결 로드맵 이름 표시. 개인 이동 경로·기록 시각·계정 ID·좌표 숫자 표시 없음.
- 태그가 없으면 빈 태그 영역 숨김 · 닉네임과 장소명은 기존 추천 저장소의 공개 표시값 사용.
- 같은 장소(같은 장소 번호 place_no)를 여러 공개 로드맵이 쓰면 핀은 하나 · 카드 안에 로드맵 후보(로드맵 이름 · 작성자 닉네임 · 별점)를 리뷰 많은 순으로 보여 주고 하나를 고르면 「로드맵 보기」 · 「여기로 안내」 대상 확정 · 처음엔 리뷰 가장 많은 로드맵이 골라진 상태.
- 묶음 핀을 누르면 같은 카드 자리에 장소 후보 목록(장소명 · 로드맵 수 · 리뷰 많은 순) · 하나를 누르면 그 장소 카드로 바뀜 · 지도 확대는 자동으로 하지 않음 · 사람이 확대하면 묶음이 풀림.
- 「여기로 안내」: 기존 안내 확인 화면에서 선택 장소 확인 → 기존 길안내 요청 결과 처리. 기존 성공·실패·시간 초과 문구 및 별점 자격 기록 정책 유지. 버튼 한 번 누른 것만으로 안내 성공 기록 생성 금지.
- 「로드맵 보기」: 고른 로드맵 상세(B-04) 진입 · 기존 장소 순서·별점·안내 흐름 유지.
- 다른 핀 선택 시 카드 교체 · 카드 닫기는 지도 유지 · 시도 변경 시 카드 닫기 · 지도를 밀어 선택 장소가 화면 밖으로 나가도 카드는 닫을 때까지 유지.
- 뒤로 순서: 안내 확인 팝업 → 장소 카드(후보 목록에서 연 카드면 후보 목록으로) → 후보 목록 닫기 → 기존 추천 뒤로 동작. 상세 · 랭킹에서 돌아오면 같은 지도 위치 · 확대(지도를 그리는 쪽 메모리) · 선택 장소(ViewModel 의 place_no) 복원(프로세스 재생성은 3-1).

### 2-4. 기존 추천 목록·상세(B-02~B-06) (수정: PR #60 리뷰 — N9 결정)

- 기존 지역별 랭킹·태그별 보기·동행자 필터·로드맵 상세·별점 수정·안내 동작 유지 · 시군구 탭 → B-02 이동은 지금 그대로.
- 지도 범위 · 시도 이동을 기존 목록의 정렬·필터 값에 덮어쓰지 않음. 시도 칩은 지금처럼 고른 시도 값을 바꾸고 지도는 그 값을 따라 이동할 뿐.
- 별점은 안내 성공 이력이 있는 로드맵만 저장 가능. 별점 버튼 항상 표시 및 안내 전 설명 변경은 별도 #51 후속 PR #58을 통합 시 확인할 의존 사항이며 이 기능에서 되돌리지 않음.
- #55의 홈 가로 카드 구역은 이번 화면 변경 대상 밖. 위치 동의는 #55 의 `LOCATION_RECO` 동의를 재사용(N4) · `LOCATION_RECO` 는 출시 전이라 #55 동의 카드 · 설정 행 문구에 「추천 지도」 목적을 먼저 반영(N9 ① 초안 · 성호님 #64 후속) · 출시 시점부터 넓은 문구로 시작하므로 재동의 없음 · #55 문구 반영(성호님 #64 후속) 뒤 위치 사용.

## 3. 상태

### 3-1. 추천 UiState의 지도 표시 정보 (수정: PR #60 리뷰 — 좌표 · 지도 조작 값은 ViewModel 상태에 두지 않고 계산 결과만)

좌표 규칙(#55 와 같음 · 예외 없음): 좌표(내 위치 · 공개 장소 좌표)와 좌표를 담은 지도 조작 값(지도 가운데 · 화면 범위)은 UiState · SavedStateHandle · 로그 어디에도 두지 않음. ViewModel 상태에는 좌표가 아닌 계산 결과만 둠. 좌표는 지도를 그리는 쪽(지도 렌더러 경계 · 저장소에서 바로 받는 지도 소스)에만 둠.

| 칸(ViewModel UiState) | 값·역할 |
|---|---|
| 첫 맞춤 기준 종류 | 내 위치 10km / 고른 시도 / 전국(N11) — 종류만 · 좌표 없음 |
| 첫 맞춤 끝남 | 예 / 아니오 — 첫 맞춤 1회를 마쳤거나 사람이 지도를 밀거나 시도를 누르면 예 · 늦은 위치 응답이 지도를 덮어쓰지 않게 하는 기준 |

지도를 그리는 쪽(UiState 밖)만 가지는 값:

| 값 | 받는 곳 → 쓰는 곳 | 수명 |
|---|---|---|
| 공개 장소 좌표(장소 번호 · 좌표 · 순위용 리뷰 수) | 저장소에서 바로 받는 지도 장소 소스 → 핀 · 묶음 그리기 · 화면 범위 · 50개 한도 계산 | 지도가 살아 있는 동안 메모리 |
| 내 위치 | 위치 사용 허용 = 예 일 때 저장소(위치)에서 1회 받음 → 국내 판정 · 10km 맞춤 · 내 위치 점 | 메모리만 · 국내 밖이면 즉시 버림 · 허용 = 아니오면 지움 |
| 지도 가운데 · 확대 단계 · 화면 범위 | 지도 렌더러 카메라 | 같은 프로세스 안 메모리만 · SavedStateHandle · 저장 상태 번들(rememberSaveable 포함)에 넣지 않음 |
| 시도 경계 범위 | 지도 자산 → 시도 탭 이동 | 자산 |

- 결정 숫자(반경 10km · 표시 한도 50 · 위치 조회 시간 제한)는 한 곳(설정 상수)에서 관리.
- 화면 범위 · 묶음 · 50개 한도 계산은 좌표를 가진 지도 그리는 쪽에서 하고, ViewModel 로는 장소 번호 · 개수 · 결과 종류만 넘김. 후보 목록 · 로드맵 후보의 「리뷰 많은 순」은 ViewModel 이 저장소의 좌표 없는 값(리뷰 수)으로 정함.
- SavedStateHandle 에는 시도 · 시군구 · 선택 장소 번호 · 고른 로드맵 번호만 · 재진입 시 공개 여부·존재 여부·동의 재검증 · 삭제·비공개로 바뀐 장소는 복원하지 않음.
- 지도 위치를 복원값으로 저장하면 사실상 내 위치를 저장하게 되므로 프로세스 재생성 뒤엔 지도 위치를 복원하지 않고 첫 맞춤 규칙을 다시 적용(위치는 허용 조건 확인 뒤 다시 조회).
- 로그 · 화면 문구에 좌표 · 지도 가운데 · 화면 범위 숫자 없음(로그엔 예외 종류 이름만).
- 기존 `RecommendedPlace` 주석 「좌표는 … 화면 상태 · 로그에 넣지 않음」은 그대로 지킴 — 지도 예외 없음. 지도 핀 그리기는 화면 상태가 아닌 지도 소스 경로로 씀(주석의 쓰는 곳 목록에 「지도 핀 그리기(지도 그리는 쪽)」만 더함).
- 지도를 그리는 쪽이 저장소에서 지도 장소 소스 · 위치를 받는 연결 방법은 android-architecture 규칙 4(자료원은 저장소 거쳐) · 5(UDF) 안에서 정함(N16).

## 4. 데이터 (수정: PR #60 리뷰 — N9 결정 · 좌표는 지도 그리는 쪽에만)

### 4-1. 앱 모델 · 자산

- 기존 추천 시드 및 `LocalRecommendationRepository`가 제공하는 공개 완료 여행과 좌표가 있는 장소만 대상.
- 핀 하나 = 장소 하나(장소 번호 place_no) · 그 장소를 쓰는 공개 로드맵(trip_no) 목록을 붙임 · 장소 번호가 다르면 좌표가 같아도 다른 장소(가까우면 묶음 핀).
- 읽는 자료: 장소번호 · 장소명 · 장소 좌표 · 태그 · 로드맵 번호 · 로드맵 이름 · 공개 닉네임 · 지역 · 공개 상태 · 별점 참여 수. 기기 안 계산 및 표시 용도. 장소 좌표는 저장소 → 지도 장소 소스 → 지도 그리는 쪽으로만 가고 ViewModel 상태로 가지 않음(3-1).
- 리뷰 많은 장소 순위 = 장소별 리뷰 수(그 장소를 쓰는 공개 로드맵들의 별점 참여 수 합 · N12 추천) 많은 순 · 같으면 장소 번호 순.
- 지도 자산(새로 앱에 묶음): OpenStreetMap 자료로 만든 한국 전국 벡터 지도 · 스타일 · 글꼴 · 아이콘 · 시도 경계 범위(시도 탭 이동용). 자산 안 원격 주소 0개. 형식 · 확대 단계 · 크기는 N8.
- `assets/maps/SOURCES.txt` 갱신: 새 자산 문단(출처 「Copyright OpenStreetMap contributors」 · ODbL 1.0 · 받은 날 · 받은 곳 · 만든 도구 · 확대 단계 · 범위) 추가 · 기존 roadmaps.json 문단(「map SDK 를 쓰지 않음」)은 그 파일 한정임을 구분해 적음 · MapLibre 라이선스 고지를 `assets/licenses/` 에 추가.

### 4-2. 위치 · 동의

- 현재 위치는 `LOCATION_RECO` 동의(#55 · 표준 미등록 제안 코드 — #55 미확정 N17 · 이 스펙 N13) 최신 이력이 동의함이고 정차 · 앞 화면일 때(3-1 위치 사용 허용)만 조회 · 지도를 그리는 쪽이 저장소에서 받아 기기 메모리 값만 사용 · 국내 판정 · 첫 맞춤 · 내 위치 점에만 씀 · UiState · SavedStateHandle · 앱의 디스크 · 로그 · 분석 · 자체 서버에 저장 · 전송 없음 · ViewModel 에는 결과 종류(국내 · 국내 밖 · 실패)만.
- 공개 장소 좌표도 같은 규칙 — 지도 그리는 쪽에만 · UiState · SavedStateHandle · 로그에 없음(#55 3-5 와 같은 규칙 · 예외 없음).
- 동의 기록은 #55 가 만든 동의 이력(user_consent_hist · consent_type_cd · consent_yn)을 읽기만 함 · 이 기능은 동의 행을 쓰지 않음(동의 받는 자리 = #55 홈 카드 · 설정 C-03 · N10).
- 동의 목적 확대(N9 결정): `LOCATION_RECO` 는 출시 전이라 #55 동의 카드 · 설정 행 문구에 「추천 지도」 목적을 먼저 반영(N9 ① 초안 문구 · 성호님 #64 후속 작업 · #64 는 home-nearby 로 머지됨) → 출시 시점부터 넓은 문구로 시작하므로 재동의 없음. #55 문구 반영(성호님 #64 후속) 뒤 위치 사용 · 그 전엔 위치 조회 없는 부분(지도 · 시도 이동 · 핀 · 카드)만.

### 4-3. 서버

- 서버 테이블·API·DB 스키마 변경 없음. 새 동의 유형 없음(`LOCATION_RECO` 재사용).

### 4-4. 최소 수집 점검

- 지도 그리기는 앱 자산만 씀 · 지도 타일 · 스타일 · 글꼴 요청을 포함해 기기 밖 요청 없음 → 지도 위치 · 화면 범위 · IP 가 지도 공급자에게 가는 경로 없음.
- 핀 · 닉네임 · 별점 · 장소 기록 · 선택 기록 · 현재 위치 전송 없음.
- 비공개 여행·정확한 기록 시각·이동 이력·계정 식별자·VIN·기어·속도·토큰 전송 없음.
- 기기 안에서도 좌표(내 위치 · 공개 장소)는 지도 그리는 쪽 메모리에만 · UiState · SavedStateHandle · 로그에 없음(M41).
- MapLibre 의 원격 수집 기능 · 네트워크 요청은 켜지 않음 · 구현 첫 단계 측정에서 네트워크 요청 0 확인(M31).

### 4-5. 쓴 표준 용어 · 사전에 없는 단어

- 쓴 용어(표준 v0.35): place_no · place_nm · trip_no · user_consent_hist · consent_type_cd · consent_yn · CONSENT_TYPE.
- 사전에 없는 코드값: `LOCATION_RECO`(CONSENT_TYPE · #55 제안 · 표준 등록 필요 · #55 N17 · 이 스펙 N13). 이 스펙은 새 이름을 더하지 않음.
