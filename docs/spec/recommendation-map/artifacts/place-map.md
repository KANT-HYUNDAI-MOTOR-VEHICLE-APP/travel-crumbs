# 추천 첫 화면 지도·공개 장소 핀 탐색 스펙 초안

## 1. 요약 (수정: 사용자 전국 지도 방향 확정)

- 추천 지역 선택 아래 빈 영역에 지도를 표시하고 공개 장소 핀 선택 → 장소 정보 → 기존 안내 또는 로드맵 상세로 연결하는 기능.
- 핀·닉네임·별점 데이터 범위는 기존 시연용 추천 시드 및 기기 안 공개 완료 여행뿐이며 해당 자료의 서버 조회·전송·DB 변경 없음.
- 사용자 선택은 「전국 지도까지 연결(추가 지도 서비스·이용 조건 검토)」로 확정. 지도 업체·외부 지도 요청 및 동의·이용 조건·주변 반경·지역 선택 동작은 미확정 표의 결정 후 구현 가능한 상태이며 이 문서는 Draft 검토용 초안.

## 2. 화면

### 2-1. 추천 지역 선택(B-01) (수정: 전국 지도 방향과 서비스 미확정 구분)

| 요소 | 표시·행동 |
|---|---|
| 기존 머리 | 「어느 지역으로 갈까요?」·시도 칩·시군구 선택 유지 |
| 지도 영역 | 지역 선택 요소 아래 남은 영역 사용 · 창 크기가 작아도 지역 선택과 장소 카드의 주요 행동에 접근 가능 |
| 데이터 출처 | 현재 저장소가 시연 자료를 포함하는 동안 「시연용 데이터」 표시 유지 · 실제 다른 사람이 서버에 올린 최신 기록이라는 표현 금지 |
| 최초 지도 | 위치 이용에 필요한 동의가 확인되고 위치를 얻으면 현재 위치 주변 공개 장소 표시 · 동의 전·위치 불가 시 지역 선택 가능 상태 유지 |
| 지역 선택 지도 | 사람이 고른 시도·시군구의 공개 장소 범위 표시 · 이전 선택 장소 카드는 닫음 · 실제 지역 선택과 B-02 이동 관계는 N5 확정 필요 |
| 장소 핀 | 선택 범위의 공개 추천 로드맵에 포함된 장소 · 비공개·미완료 여행 제외 · 좌표 없는 장소 제외 |
| 내 위치 | 동의·조회 성공 조건에서만 표시 · 위치를 얻지 못했을 때 임의 위치나 시연 위치를 내 위치로 표시 금지 |
| 핀 출처 | 시연용 장소와 기기 공개 장소를 실제 사용자 서버 기록으로 오인하지 않도록 전체 시연 표시 유지 |
| 지도 출처 | 전국 지도를 제공할 서비스 확정 뒤 해당 출처·표시·조건 준수(N1) · 기존 OpenStreetMap 자료를 사용하는 부분의 출처 유지 |
| 로딩 | 「지도를 준비하고 있어요」 또는 「내 위치를 확인하고 있어요」 정지 문구 · 자동 회전·깜박임 없음 |

주행 상태별 규칙:

| 판정 | 지도·핀·카드 | 위치 조회·사용자 입력 |
|---|---|---|
| PARKED | 현재 지도 상태에 따라 표시 | 동의 확인 뒤 조회 및 터치 허용 |
| DRIVING | 기존 주행 전용 화면으로 전환 · 지도·카드 숨김 | 조회 중지·늦은 결과 폐기 · 핀·안내 버튼 입력 미수락 |
| UNKNOWN | DRIVING과 동일 | DRIVING과 동일 |

화면이 뒤로 가거나 앱이 백그라운드로 이동하면 현재 위치 조회 중지 및 늦은 결과 폐기. 다시 앞에 오면 정차·동의 조건 재확인.

### 2-2. 지도 상태별 표현 (수정: 기존 자산 한계와 전국 연결 목표 구분)

| 상태 | 표현·회복 |
|---|---|
| 동의 확인 전 | 현재 위치 조회 없음 · 지역 선택 가능 · 현재 위치 이용 동의 방식 N4 |
| 현재 위치 획득 중 | 위치 확인 정지 문구 · 지역을 직접 고르면 위치 응답이 뒤늦게 와도 선택 지역 덮어쓰기 금지 |
| 위치 있음·공개 장소 있음·지도 지원 | 현재 위치 주변의 실제 대상 핀 표시 · 반경·개수 N3/N6 |
| 위치 없음 | 「현재 위치를 확인하지 못했어요. 지역을 골라 주세요」 · 위치 숫자·임의 주소 없음 |
| 공개 장소 0개 | 「이 지역에는 아직 공개된 장소가 없어요」 · 다른 지역 선택 가능 · 전국 자료를 주변 자료처럼 자동 대체하지 않음 |
| 지도 범위 밖 | 「이 지역의 지도는 아직 준비되지 않았어요」 초안 · 존재하는 장소 자료와 지도 부재 구분 · 최종 표현 N2 |
| 지도 읽기 실패 | 「지도를 불러오지 못했어요」 · 기존 지역별 추천 목록 이용 가능 · 가짜 도로·빈 격자를 실제 지도로 표시 금지 |
| 일부만 지도 지원 | 지원되는 실제 지도 범위만 표시하고 범위 밖 장소가 있음을 알림 · 경계 밖 핀을 안쪽으로 이동시키거나 삭제 사실을 숨기지 않음 · 최종 범위 정책 N2 |

실제 지도 자산 제약: 현재 `assets/maps/roadmaps.json`은 속초 도심·설악산 방향·경포·강릉~주문진·양양의 5구역만 포함하며 이것만으로 전국 지도 목표를 충족하지 못하는 상태. 전국 지도 연결 방향은 확정되었으나 제공 서비스·지원 범위·오프라인/통신 실패 처리는 N1/N2 확정 필요. 기존 상세의 점선 경로 그림은 장소 관계를 보여 주는 미리보기이며 주변 탐색 지도 대용으로 확정하지 않은 상태.

### 2-3. 핀 선택 장소 카드

- 지도와 같은 화면 안의 카드 하나 표시 · 지도 가림과 창 폭 변경에도 제목·두 주요 행동 접근 가능.
- 장소명·공개 로드맵의 작성자 닉네임·선택 장소의 태그·연결 로드맵 이름 표시. 개인 이동 경로·기록 시각·계정 ID·좌표 숫자 표시 없음.
- 태그가 없으면 빈 태그 영역 숨김 · 닉네임과 장소명은 기존 추천 저장소의 공개 표시값 사용.
- 「여기로 안내」: 기존 안내 확인 화면에서 선택 장소 확인 → 기존 길안내 요청 결과 처리. 기존 성공·실패·시간 초과 문구 및 별점 자격 기록 정책 유지. 버튼 한 번 누른 것만으로 안내 성공 기록 생성 금지.
- 「로드맵 보기」: 해당 장소가 속한 추천 로드맵 상세(B-04) 진입 · 기존 장소 순서·별점·안내 흐름 유지.
- 다른 핀 선택 시 카드 교체 · 카드 닫기는 지도 유지 · 지역 변경 시 카드 닫기.
- 뒤로 순서: 안내 확인 팝업 → 선택 장소 카드 닫기 → 기존 추천 뒤로 동작. 상세에서 돌아오면 가능한 경우 같은 지역·선택 장소 복원.
- 겹친 핀은 하나의 장소를 임의 선택하지 않고 겹침을 나타내며 선택 후보를 구분 가능한 방식으로 제공(N6). 동일 장소가 서로 다른 로드맵에 있으면 로드맵·작성자를 구분해 「로드맵 보기」 대상 확정.

### 2-4. 기존 추천 목록·상세(B-02~B-06)

- 기존 지역별 랭킹·태그별 보기·동행자 필터·로드맵 상세·별점 수정·안내 동작 유지.
- 지도 탐색 필터를 기존 목록의 정렬·필터 값에 몰래 덮어쓰지 않음. 지도 상태와 목록 선택의 연동 시점은 N5로 확정.
- 별점은 안내 성공 이력이 있는 로드맵만 저장 가능. 별점 버튼 항상 표시 및 안내 전 설명 변경은 별도 #51 후속 PR #58을 통합 시 확인할 의존 사항이며 이 기능에서 되돌리지 않음.
- #55의 홈 가로 카드 구역은 이번 화면 변경 대상 밖. 해당 스펙의 현재 위치 정책은 대조 자료이며 병합·승인된 공통 동의로 간주하지 않음.

## 3. 상태

### 3-1. 추천 UiState의 지도 표시 정보

| 칸 | 값·역할 |
|---|---|
| 탐색 기준 | 현재 위치 주변 / 선택 지역 |
| 지도 상태 | 동의 필요·위치 확인 중·위치 불가·지도 준비 중·준비됨·빈 장소·범위 밖·읽기 실패 |
| 선택 지역 | 시도·시군구 · 기존 지역 선택값과 역할 중복 없음 |
| 표시 지도 | 출처·실제 지원 범위·그릴 지도 요소 · UI에 필요한 표시 정보 |
| 장소 핀 목록 | 안정적인 장소·로드맵 식별키·표시 위치·선택 여부·겹침 여부 |
| 선택 장소 카드 | 없음 또는 장소명·태그·닉네임·로드맵 이름·행동 가능 상태 |
| 안내 요청 상태 | 기존 요청 중·성공·실패 상태와 일치하는 단일 상태 |
| 표시 메시지 | 위치 불가·지도 실패·안내 결과 등 · 소비 후 지움 |

- 원본 현재 위치는 화면 복원·로그·영구 저장 대상 아님. 화면에는 지도에 필요한 표현만 전달.
- 지역·선택 장소의 식별값은 복원 가능하나 재진입 시 공개 여부·존재 여부·동의 재검증. 삭제·비공개로 바뀐 장소는 복원하지 않음.
- 주변 반경·핀 한도·시간 제한은 확정 뒤 한 곳에서 관리. 초안 숫자를 확정값으로 구현하지 않음.

| 동의 미확인·거부·철회 | 위치 조회 0 · 지역 선택 유지 · 메모리의 현재 위치·주변 거리 제거 |

| 위치 조회 실패·시간 초과 | 위치 불가 · 지역 선택 회복 안내 |
| 시도 선택 | 이전 카드 닫기 · 선택 지역 기준 지도 표시 갱신 · 기존 시군구 선택 유지 |

| 핀 선택 | 해당 장소 카드 표시 · 저장·안내 요청 없음 |
| 안내 버튼 | 기존 확인·요청 흐름 · 중복 요청 방지 · 성공 때만 해당 로드맵 별점 자격 기록 |
| 로드맵 보기 | B-04 진입 · 복귀 시 지역·선택 장소 유효성 확인 |
| 공개 자료 변경 | 선택 범위 재계산 · 비공개·삭제된 핀과 카드 제거 |
| 주행·모름·백그라운드 | 지도 조작 중지 · 위치 결과 폐기 · 늦은 응답으로 화면 재전환 금지 |
| 프로세스 재생성 | 지역·장소 식별값 재검증 · 현재 위치 재사용 없음 |

## 4. 데이터 (수정: 로컬 장소 자료와 지도 서비스 요청 분리)

- 기존 추천 시드 및 `LocalRecommendationRepository`가 제공하는 공개 완료 여행과 좌표가 있는 장소만 대상.
- 장소 식별은 로드맵+장소 조합으로 구분 · 서로 다른 로드맵의 같은 번호나 같은 좌표가 충돌하지 않도록 계약 확정.
- 읽는 자료: 장소명·장소 좌표·태그·로드맵 번호·로드맵 이름·공개 닉네임·지역·공개 상태. 기기 안 계산 및 표시 용도.
- 현재 위치는 동의 후 조회한 기기 메모리 값만 사용 · 앱의 디스크·로그·추적·분석·자체 서버에 저장·전송 없음. 정확한 사용자 위도·경도를 별도 API 파라미터로 보내는 기능은 이번 확정 범위에 없음.
- 서버 테이블·API·DB 스키마 변경 없음. 새 동의 유형이 필요한지는 N4로 확정하며 이름·보관 방식을 임의 추가하지 않음.
- 전국 지도 서비스 검토·연결 방향은 승인된 상태이나 업체·계약·과금·동의·외부 요청의 세부 범위는 미확정. 온라인 타일 요청의 타일 식별값으로 지도 뷰포트 지역이, 통신 과정에서 IP 주소가 제공자에 노출될 수 있으므로 「기기 밖으로 아무 정보도 나가지 않음」으로 안내하지 않음. 현재 위치 중심 뷰포트 역시 대략적인 위치를 드러낼 수 있어 N1/N4의 서비스 조건·동의 검토 대상.
- 지도 타일 요청과 별도 정확한 사용자 좌표 API 전송은 구분하며, 타일 제공자에 핀·닉네임·별점·장소 기록 원문·선택 기록을 함께 전송하지 않음. 서비스 SDK의 기본 수집·원격 분석 여부는 업체 확정 시 검증 대상.
- 비공개 여행·정확한 기록 시각·이동 이력·계정 식별자·VIN·기어·속도·토큰 전송 없음.

## 5. API 계약 변경 (수정: 자체 서버 계약과 외부 지도 요청 구분)

자체 서버 API 변경 없음. 경로·메서드·요청·응답·오류 코드 추가 없음. OpenAPI 변경 조각 없음. 핀·카드 선택은 기기 안 상태 변경이며 안내 요청은 기존 계약 유지. 외부 지도 서비스의 타일·스타일·리소스 요청은 N1 확정 후 요청 항목·공급자·인증·수집 범위 문서화 대상이며 자체 서버 API 변경 없음과 외부 네트워크 요청 없음은 서로 다른 의미.
