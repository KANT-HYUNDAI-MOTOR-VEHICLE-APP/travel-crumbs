# Gleo 음성 기능 브리핑

2026-11-10 · Pleos 에뮬레이터 · 사람 직접 발화 67건 · 이슈 #25 · #69 · PDF: [`gleo-voice-report-20261110.pdf`](gleo-voice-report-20261110.pdf)

## 1. 기능과 말

**말하는 법:** 「글레오」 → 대답 → 삐 소리 → 반 박자 쉬고 5초 안에 말하기.

| 기능 | 되는 말 |
|---|---|
| **장소 기록** | 이 장소 기록해 줘 · 장소 기록해 줘 · 여행 기록해 줘 · 이거 기록해 줘 · 기록해 줘 |
| **오늘 기록 보기** | 오늘 기록 보여줘 · 내 여행 기록 보여줘 · 보여줘 |
| **경로 추천(근처)** | 경로 추천해 줘 · 근처 추천해 줘 |
| **경로 추천(지역)** | 경주 경로 추천해 줘 · 속초 경로 추천해 줘 |
| **기록 멈춤 · 재개** | 잠깐 멈춰 줘 · 멈춰 줘 · 다시 기록해 줘 · 계속 기록해 줘 |
| **여행 종료** | 여행 끝낼게 · 종료해 줘(화면 확인 팝업 → 사람이 「종료」) |
| **앱 열기** | **트래블 크럼스 앱** 열어 줘 |

## 2. 문제

- **문제 1 — 일반 추천 질문은 Gleo 가 가져감.** 「추천해 줘」 · 「서울 근처 여행 추천해 줘」 · 「경주 추천 코스 알려 줘」는 Gleo 웹 검색으로 감. 「경로 추천」 말투면 우리 앱으로 옴.
- **문제 2 — 말 앞부분이 잘림.** 「제주도 근처 추천해 줘」가 「주 근처 추천해줘」 · 「저 추천해줘」로 받아 적혀 지역이 빠짐 → 현재 위치로 추천 → 에뮬레이터 위치가 성남에 고정이라 **늘 서울 강남구**가 나옴. 짧은 조각(「로」 · 「형」)만 잡힌 경우도 있음. 삐 소리 뒤 반 박자 쉬면 줄어듦.
- **문제 3 — 앱 이름 받아쓰기.** 「Travel Crumbs 열어 줘」가 「트러블 클럼스」 · 「더블 클럼스」 · 「프럼스」로 적혀 앱을 못 찾음. 「트래블 크럼스 앱 열어 줘」는 됨.
- **문제 4 — 없는 기능.** 「1번 선택할게」(목록 고르기)는 지원 안 함 · 「팔각정 코스로 해 줘」는 Gleo 내비가 가져감.

## 3. 속도

| | 말 끝 → Gleo 가 결과 받음(중앙값) | 건수 |
|---|---|---|
| 앱이 켜져 있을 때 | **2.04초**(최대 3.21초) | 27 |
| 앱이 꺼져 있을 때(콜드) | **3.05초** | 3 |

- 시간의 대부분은 Gleo 가 씀(판단 약 1.4초 + 결과 받기 0.5초). 앱 처리는 약 0.05초(콜드는 기동 포함 약 1초).
- Gleo 7초 한도를 넘긴 경우: 에뮬레이터 **재부팅 직후** 기록 2건(내비 위치 조회가 10초 걸림). 이때도 장소는 한 번만 저장됨.

## 4. 한 실험과 이유

| 실험 | 왜 | 결과 |
|---|---|---|
| ADB 로 Action 직접 보내기(웜 · 콜드 20회씩 · 결함 주입) | 음성 없이 앱 처리 · 7초 기한 · 실패/미확인 안내 확인 | 앱 콜백 웜 0.05초 · 콜드 2.2초 · 결함 응답 스펙대로 |
| 합성 음성(Windows TTS)으로 말하기 | 사람 없이 음성 시험 | 실패 — 스피커 → 마이크 소리가 너무 작음 |
| 사람 발화 1차 | 실제 Gleo 가 우리 함수를 부르는지 | Gleo 는 골랐지만 **앱이 못 받음** → action 이름에 패키지명이 붙어 옴(공식 문서와 다름) → 수정 |
| 수정 뒤 재시험 | 고쳐졌는지 | 기록 · 보기 성공(약 2초) |
| develop 병합본 시험 | 기기 안 저장(Room) 구조에서도 되는지 | 기록 0 → 1 성공 |
| #69 함수 3개(기록 · 여행 제어 · 정보) | 새 기능 동작 | ADB 로 전부 확인 · 「경주」 → 경주시 추천 화면 · 종료는 팝업만 |
| 추천 문장 시험 | Gleo 가 추천을 우리 앱으로 보내는지 | 「추천해 줘」류는 웹 검색 · 「경로 추천」류는 우리 앱 |
| 함수 설명 강화 · 앱 호출어(invokeWord) | 웹 검색으로 새는 추천 줄이기 | 「경로 추천」 말투에서 효과 |
| 빈 지역 버그 수정 | 「경로 추천해줘」가 입력 실패 | Gleo 가 지역 없으면 "" 를 보냄 → 「말하지 않음」으로 처리 → 5건 성공 |
| 반복 시험(같은 말 여러 번) | 성공률 · 속도 분포 | 의도한 명령 모두 성공 |
| 콜드 3회 | 앱이 꺼져 있을 때 속도 | 3회 모두 성공 · 약 3초 |
| 앱 열기 시험 | OPEN 함수를 빼도 열리는지 | 「트래블 크럼스 앱 열어 줘」로 성공 |

## 5. DB 참고 — Gleo 기능이 쓰는 데이터(데이터 표준정의서 v0.4 기준)

| Gleo 기능 | 테이블 · 칸 | 읽기 · 쓰기 |
|---|---|---|
| 장소 기록 | `trip_place_dtl`(`trip_no` · `lat` · `lng` · `recorded_at` · `draft_yn`='Y') · `trip_mst.place_cnt` | 쓰기 |
| 기록 멈춤 · 재개 | `trip_mst.trip_status_cd`(TRIP_STATUS: RECORDING ↔ PAUSED) · `trip_status_hist` | 쓰기 |
| 여행 종료 | 쓰기 없음(확인 팝업만) — 사람이 「종료」를 누르면 `trip_status_cd`=COMPLETED · `end_at` | — |
| 오늘 기록 보기 | `trip_place_dtl.recorded_at` · `trip_mst.trip_status_cd` · `place_cnt` | 읽기 |
| 경로 추천 | `route_reco_dtl` · `route_reco_place_dtl` · `place_mst` | 읽기 |

- Gleo 기능은 새 테이블 · 칸을 만들지 않음 — 화면 버튼과 같은 저장 경로를 씀.
- 좌표는 Gleo 콜백 · 로그에 넣지 않음(추천 응답은 지역 이름 · 로드맵 이름만).
