## 5. 성능 지표

### 5.1 실제 음성(성공 7건)

| 구간 | 최소 | 중앙값 | 최대 | 누가 |
|---|---|---|---|---|
| Gleo 판단(받아쓰기 → 함수 선택) | 1.12초 | **1.42초** | 1.64초 | Gleo 서버 LLM |
| 앱 처리(수신 → 콜백 전송) | 0.002초 | **0.045초** | 0.20초 | 우리 앱 |
| Gleo 수락(콜백 → 수신) | 0.50초 | **0.50초** | 0.51초 | Gleo(거의 고정) |
| **말 끝 → 결과 수락** | 1.71초 | **1.97초** | 2.25초 | 합계 |

→ 전체 시간의 약 70%가 Gleo 판단 · 25%가 Gleo 수락 대기 · 앱은 5% 미만.

### 5.2 앱만(ADB · #25 성능평가 · 20회씩)

| 상태 | 앱 콜백 p50 / 최대 | Gleo 수신 p50 / 최대 |
|---|---|---|
| 웜(앱 실행 중) | 51 / 74 ms | 549 / 566 ms |
| 콜드(앱 꺼짐) | 2,203 / 2,387 ms | 2,705 / 2,888 ms |

→ 앱이 꺼져 있으면 앱 기동만큼(약 2초) 더 걸림. 실제 음성 + 콜드는 약 4초로 추정(미측정).
