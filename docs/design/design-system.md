# Travel Crumbs 디자인 시스템 제작 지시서

## 1. 제작 목적

- Pleos 차량 화면용 Travel Crumbs 디자인 시스템
- 운전 중 또는 동승자가 아이를 돌보는 상황에서도 빠른 정보 확인
- 1~2초 안에 핵심 상태와 행동 파악
- 첨부된 Pleos 에뮬레이터 화면을 실제 시연 환경으로 사용
- Figma에서 수정 가능한 컴포넌트·Variant 구성

## 2. 브랜드 컨셉

- 서비스명: `Travel Crumbs`
- 핵심 개념: 사라지는 빵 부스러기 대신 남겨두는 디지털 여행 흔적
- 사용자 가치: 여행 기록 · 재방문 · 다른 여행자의 흔적 따라가기
- 디자인 키워드: 모던 · 따뜻함 · 경로 · 흔적 · 발견
- 그래픽 모티프: 점선 경로 · Crumb 노드 · 장소 핀
- 핵심 문장: `내가 다시 찾아가고, 누군가도 그 흔적을 따라갈 수 있도록`
- 제외 요소: 동화풍 · 빵 일러스트 · 과자집 · 유아적인 표현 · 베이커리 스타일

## 3. Pleos 화면 제약

- 첨부된 에뮬레이터 화면의 오른쪽 앱 영역만 사용
- 왼쪽 Driving View 수정 금지
- 상단 상태바 수정 금지
- 하단 차량 제어 영역 수정 금지
- 전체 화면을 덮는 앱 화면 금지
- 모바일 세로형 UI 복제 금지
- Landscape 중심 설계
- 앱 영역 크기 변경에 대응하는 반응형 구조
- 축소된 Portrait 영역에서도 핵심 기능 유지
- 차량 화면 구조 안에서 실제 크기 확인

## 4. Pleos 차량 UX 원칙

- 운전자·동승자가 1~2초 안에 이해할 수 있는 정보량
- 한 화면에 하나의 주요 행동 강조
- 운전 중 핵심 상태와 핵심 행동만 노출
- 정차 후 상세 입력·수정 기능 노출
- 한 손 조작이 가능한 단순한 인터랙션
- 드롭다운·다단 메뉴 최소화
- 키보드 입력보다 프리셋·최근 항목·Gleo 음성 입력 우선
- 동영상·자동 애니메이션·텍스트 자동 스크롤 제외
- 반복적인 화면 전환 최소화
- 아이콘과 텍스트 라벨 동시 제공
- 배경과 텍스트 대비율 4.5:1 이상
- 처리 지연 시 Loading 상태 즉시 표시
- 주행 제한 시 `CarUxRestrictions` 기준 UI 축소·비활성화
- 포그라운드 복귀 시 진행 중 여행 상태 복원
- 주간·야간 환경의 가독성 고려
- 주행 중 상세 지도 탐색·후기 입력·설정 변경 제외

## 6. 타이포그래피

- 기본 서체: `Asta Sans`
- 대체 서체: `Noto Sans KR`, `sans-serif`
- 화면 제목: 40px / Bold
- 섹션 제목: 32px / Bold
- 카드 제목: 28px / SemiBold
- 주요 버튼: 28px / Bold
- 본문: 24px / Regular
- 보조 정보: 20px / Regular
- 최소 글자 크기: 20px
- 중요 정보 글자 높이: 5mm 이상
- 보조 정보 글자 높이: 3mm 이상
- 문장·단락: 최대 3줄
- 긴 문장보다 짧은 명사형 문구 우선
- 작은 캡션을 여러 개 배치하는 구성 제외
- 공간이 부족할 경우 글자 축소보다 정보 삭제·요약 우선

## 7. 간격과 형태

- 기본 간격 단위: 8px
- 앱 영역 바깥 여백: 24px
- 섹션 간격: 24px
- 카드 내부 여백: 20px
- 요소 간격: 12px 또는 16px
- 카드 모서리: 16px
- 버튼 모서리: 16px
- 칩 모서리: 999px
- 일반 터치 영역: 64×64px 이상
- 주요 터치 영역: 72×72px 이상
- 주요 버튼 높이: 72px 이상
- 인접 터치 요소 사이 간격: 12px 이상
- 그림자보다 테두리와 배경 명도 차이로 영역 구분

## 8. 기본 화면 구조

- 왼쪽: NavigationRail
- 중앙: 여행 경로·장소 지도
- 오른쪽: 주요 행동·여행 상태·동행자·태그·최근 여행
- 권장 비율: NavigationRail 12% / 지도 43% / 정보 영역 45%
- 화면 영역 축소 시 우선순위:
  1. 주요 행동
  2. 여행 상태
  3. 지도·현재 위치
  4. 최근 여행
  5. 부가 정보

## 10. NavigationRail

- 메뉴: 여행 기록 · 여행 목록 · 찍힌 장소 · 설정
- 기본 상태: 투명 배경 + 흰색 아이콘
- 선택 상태: `Background/Selected` + `Brand/Secondary`
- 아이콘 크기: 32px 이상
- 아이콘과 메뉴명 동시 표시
- 선택 메뉴의 배경·아이콘·텍스트 동시 변경
- 공유·추천 메뉴 임의 추가 금지

## 11. 로고
