# ADR 0016 — 데이터 표준 정의서가 이름 · 코드값의 원본(2026-11-07 제안 · 승인 대기)

> 원본 규칙: `docs/data/README.md` · `server-architecture` 규칙 9 · `android-architecture` 「네트워크 · 세션 · 오프라인」 · `sensors` 「데이터 표준 센서의 심각도는 정의서가 정함」. 이슈 #19.

## 무엇이 있었나

- 데이터 표준 정의서(v0.2 · v0.35)와 ERD v0.2 가 저장소 **루트에 한글 이름 · 판 번호 파일명**으로 머지됨(#17).
- 하네스 어디에도 연결되어 있지 않았음 — `spec-writer` 는 스펙의 데이터 절을, `builder` 는 모델 · 리비전 · Room 엔티티를, `structure-reviewer` 는 서버 구조를 정의서 없이 처리했음. 테이블 · 컬럼 이름이 에이전트마다 달라짐.
- 같은 문서의 두 판이 나란히 있어 어느 것이 원본인지 파일만 보고 알 수 없었음.
- `docs/spec/README.md` 는 이미 「맥 ↔ 윈도우 사이에 한글 파일 이름이 깨질 수 있음」을 이유로 영문 소문자 이름을 규칙으로 두고 있었음.

## 결정

- 자리: `docs/data/standard.md`(표준 정의서) · `docs/data/erd.md`(ERD) · `docs/data/archive/standard-v<판>.md`(지난 판) · 읽는 법은 `docs/data/README.md`.
- `standard.md` 는 **항상 최신판**. 판 번호는 파일 이름이 아니라 **문서 첫 줄**에. 새 판이 오면 지금 것을 `archive/` 로 내리고 새 판을 `standard.md` 로 올림.
- 읽는 때: `spec-writer`(데이터 · API 계약 절 전) · `builder`(모델 · 스키마 · 리비전 · Room `@Entity` 전) · `structure-reviewer`(서버 규칙 9). `pleos-reviewer` 는 읽지 않음.
- **「결정」인 것만 규칙으로 따름.** 정의서의 상태 칸이 「제안 · 미결 · 가안」인 항목은 스펙의 「미확정」 표로 올려 사람이 정하게 함.
- 스킬 · 에이전트 정의는 사전을 **베끼지 않고 경로만 가리킴**.
- 스펙 첫머리에 `- 데이터 표준: v<판>` 한 줄.
- 계산으로 재는 부분은 `check_data_standard.py` 가 맡고, **심각도를 정의서의 상태 칸에서 읽음** — 「결정」은 위반 · 그 밖은 경고.
- 정의서 · ERD 를 고치는 것은 **사람**. AI 는 읽기만 하고 어긋난 곳을 「미확정」 · 리뷰 표로 올림.

## 이유

- 경로를 고정하지 않으면 판이 오를 때마다 스킬 · 에이전트 · 센서 · CI 의 참조가 한꺼번에 깨짐. 읽는 쪽이 매번 「가장 큰 숫자」를 고르게 하면 언젠가 옛 판을 읽음 — 고르는 일을 없애는 쪽이 안전함.
- 사전을 스킬에 베끼면 목록이 두 곳이 되어 한 곳만 고쳐짐. `check_manifest.py` 의 `ALLOWED` 를 한 곳으로 둔 것과 같은 이유(`sensors` 「권한 허용 목록을 늘리는 길」).
- 정의서에는 사람이 아직 확정하지 않은 「제안 · 가안」이 섞여 있음. 그대로 구현하면 초안이 코드 · 마이그레이션으로 굳어 되돌리는 값이 커짐. 반대로 전부 무시하면 정의서를 둔 뜻이 없어지므로, 상태 칸을 기준으로 나눔.
- 센서가 심각도를 코드에 박으면 정의서에서 상태를 올려도 센서가 안 따라옴. 상태를 읽게 하면 규칙의 무게를 정하는 곳이 정의서 한 곳으로 모임.
- AI 가 정의서를 고칠 수 있으면 「사전에 없는 단어」를 스스로 등록해 통과시킬 수 있음 — 센서가 재는 대상을 센서를 받는 쪽이 고치는 꼴이라 규칙이 무의미해짐.

## 버린 안

| 안 | 버린 이유 |
|---|---|
| 루트에 그대로 두고 경로만 참조 | 한글 파일 이름이 맥 ↔ 윈도우에서 깨짐 · 판이 오르면 참조가 전부 깨짐 |
| 판 번호를 파일 이름에 두고 「가장 큰 숫자」를 읽게 함 | 읽는 쪽마다 고르는 규칙이 필요하고, 한 번 틀리면 옛 판으로 구현함 |
| 사전을 `server-architecture` 로 옮겨 적음 | 목록이 두 곳 — 한 곳만 고쳐져 규칙과 센서가 어긋남 |
| 「제안」도 전부 규칙으로 강제 | 확정 안 된 초안이 코드로 굳음 · 막힌 쪽이 센서를 끄게 됨 |
| 「제안」을 전부 무시 | 정의서를 둔 뜻이 없어짐 · 이름이 다시 에이전트마다 갈라짐 |
| AI 가 사전에 단어를 등록 | 센서를 받는 쪽이 센서의 기준을 고치게 됨 |
